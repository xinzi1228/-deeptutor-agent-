## 1. teach (mattpocock): HTML Lesson 生成

### 这是什么

每次理论模块完成后，Coach 自动生成一个独立的 HTML 课程文件。学生可以保存、打印、离线复习。

### 当前状态

- [x] 能力已注册: 在 `flow-theory.md` Step6 中，模块完成时 Coach 生成 Markdown 学习参考
- [x] 用法已标注: 参考文本包含"核心概念+你的成绩+薄弱点+下次继续"
- [ ] **未实现**: 生成真正的 HTML lesson（当前只输出 Markdown 文本）

### 需要做的事

| 任务 | 说明 |
|------|------|
| 设计 lesson 模板 | 基于 aetherviz-master 的 UI 模板（玻璃拟态+青绿主题），创建可复用的 HTML lesson 模板 |
| 调用 code_execution | Coach 调 `code_execution` 工具 → 跑 Python 脚本 → 用模板+学生数据生成 HTML |
| 文件存储 | 生成的 HTML 存储在 `data/user/workspace/lessons/{module_name}/` 下 |
| 前端展示 | 个人中心页面增加「我的课程」tab，列出已生成的 lesson，可点击打开/下载 |

### 生成时机

Phase1 每个模块的最后一个知识点 readiness=advance 时 → 触发 lesson 生成

## 2. aetherviz-master: 3D 交互 IOU 演示

### 这是什么

学生在学习 IOU 概念时，打开一个交互式 Web 页面——屏幕上两个矩形框可以拖动，实时显示 IOU 数字变化。抽象概念变成看得见、摸得着的体验。

### 当前状态

- [x] 能力已注册: 在 `PERSONA.md` 技能表中注册了 aetherviz-master
- [x] 用法已标注: 在 `flow-theory.md` Step1 中标注了"IOU/可视化密集型概念 → 生成交互演示"
- [ ] **未实现**: 实际的 3D 交互页面

### 需要做的两个场景

#### 场景 A: IOU 实时计算演示（最优先）

```
页面布局:
┌────────────────────────────────────┐
│          IOU 交互演示               │
│                                    │
│  ┌──────────────────────────────┐ │
│  │                              │ │
│  │   [框A: 可拖动, 蓝色半透明]    │ │
│  │        ∩                      │ │
│  │   [框B: 可拖动, 绿色半透明]    │ │
│  │                              │ │
│  └──────────────────────────────┘ │
│                                    │
│  IOU = 交集 / 并集 = 2500 / 17500 │
│       = 0.143                     │
│                                    │
│  [重置] [随机位置]                 │
│                                    │
│  提示: 拖动两个框，观察 IOU 如何变化 │
└────────────────────────────────────┘
```

**技术方案:**
- HTML Canvas + JavaScript（不需要 Three.js，2D 交互足够）
- 参考 aetherviz-master 的配色方案（青绿主题）
- 两个矩形框可鼠标拖动，实时计算 IOU
- 同时显示: IOU 值 + 色彩编码（绿=高IOU，黄=中，红=低）

#### 场景 B: 个人中心 3D 仪表盘（后续）

```
│  │ 能力雷达图 │  │  技能树(3D)    │  │
│  │ (Canvas)  │  │  (Three.js)   │  │
│  └──────────┘  └───────────────┘  │
│                                    │
│  ┌──────────────────────────────┐ │
│  │     F1 成长曲线 (折线图)       │ │
│  └──────────────────────────────┘ │
│                                    │
│  ┌──────────────────────────────┐ │
│  │     学习历史记录列表            │ │
│  └──────────────────────────────┘ │
└────────────────────────────────────┘
```

**技术方案:**
