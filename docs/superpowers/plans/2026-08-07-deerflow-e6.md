# 第三轮优化 E6 实现计划：工具错误 → 中文错误消息让 loop 继续

> 依据：`docs/superpowers/specs/2026-08-07-deerflow-borrow-design.md` E6。**现状核查**：`deeptutor/core/agentic/tool_dispatch.py:401-427` 已有 try/except——工具异常返回 `{"result_text": unknown_msg, "success": False}`，loop 继续。缺口：`unknown_error_message_factory` 签名只收 `tool_name`，pipeline 默认英文消息，**无异常原因、无截断、无建议**。E6 = 增强这三项。

## 现状（已核实）
- `tool_dispatch.py`：
  - `UnknownErrorMessageFactory` 类型（L88 附近）当前签名为接收 `tool_name` 返回 str
  - except 分支（L401-427）：`unknown_msg = factory(tool_name) if factory else f"Error executing {tool_name}: {exc}"`；`metadata={"error": str(exc)}`
- 调用点（factory 传入处）：
  - `agents/chat/agentic_pipeline.py:790`（i18n `notices.tool_unknown_error`，默认英文）
  - `agents/research/pipeline.py:2325` 和 `:2702`
  - `agents/question/pipeline.py:1941`

## 改动

### 1. `deeptutor/core/agentic/tool_dispatch.py`
- `UnknownErrorMessageFactory` 签名改为 `Callable[[str, str], str]`（`tool_name, error_str`）
- except 分支：
  ```python
  reason = str(exc)
  truncated = reason[:300] + ("…" if len(reason) > 300 else "")
  unknown_msg = (
      unknown_error_message_factory(tool_name, truncated)
      if unknown_error_message_factory is not None
      else f"工具 {tool_name} 执行失败：{truncated}"
  )
  ```
  默认消息改中文（教学平台全中文）。

### 2. `deeptutor/agents/chat/agentic_pipeline.py:790`
lambda 改为中文模板：
```python
unknown_error_message_factory=lambda tn, err: (
    f"工具 {tn} 执行失败：{err}。请检查参数是否正确，或改用其他工具；"
    "若无法继续，基于已有结果直接输出阶段性结论。"
)
```
（err 已由 tool_dispatch 截断；移除对 i18n key 的依赖或保留 key 但 lambda 优先中文）

### 3. `deeptutor/agents/research/pipeline.py:2325,2702` + `deeptutor/agents/question/pipeline.py:1941`
同步新签名 `lambda tn, err: ...`（保留各自原有语言风格，仅适配 2 参）。

### 4. 测试
- `tests/core/agentic/test_tool_dispatch.py`（或对应工具分发测试文件，先找）新增：
  - 工具抛异常 → `result_text` 含"执行失败"中文 + 异常原因片段（截断验证：超长异常只保留前 300 字符）
  - `success=False` + `metadata.error` 仍在
  - 自定义 factory 收到 `(tool_name, truncated_error)` 两参
- 回归：pipeline 现有调用处测试（research/question/chat dispatch 相关）全过
