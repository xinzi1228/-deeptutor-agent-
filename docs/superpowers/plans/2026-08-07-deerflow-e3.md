# 第三轮优化 E3 实现计划：子代理调度加固（M 部分：timeout + 并发截断）

> 依据：`docs/superpowers/specs/2026-08-07-deerflow-borrow-design.md` E3。借鉴 DeerFlow `subagent_limit_middleware.py`（单轮 task 调用超限截断）+ `executor.py`（timeout 降级）。**本轮做 M 部分**：delegate 执行加 timeout（超时降级单轮 complete fallback）+ 单轮 delegate 调用 >2 截断。L 部分（后台线程 + 进度事件 + 并行）留 P2。TDD。

## 现状（已核实）
- `delegate_expert_tool.py` execute（L149-217）：主路径 `await pipeline.run(ctx, bus)`（串行 ≤5 轮，无 timeout）；fallback 到 `complete()`（L205-217）
- `agent_loop.py` `_run_loop`：每轮 `result.tool_calls` 全部 dispatch（E1 循环检测在此前插入）

## 改动

### 1. `deeptutor/tools/delegate_expert_tool.py` — timeout
- 模块常量 `DELEGATE_TIMEOUT_SECONDS = 60`
- execute 主路径：`await asyncio.wait_for(pipeline.run(ctx, bus), timeout=DELEGATE_TIMEOUT_SECONDS)`（`import asyncio`）
- `finally: await bus.close()` 保持
- 超时（`asyncio.TimeoutError`）→ 落入外层 except → 走 fallback `complete()`（已有）；**确保超时后 bus 已 close**（try/finally 结构正确）
- 日志：超时打 `logger.warning`

### 2. `deeptutor/agents/chat/agent_loop.py` — 单轮 delegate 并发截断
- 模块常量 `_MAX_DELEGATE_PER_ROUND = 2`
- 在 E1 循环检测之后、assistant-message append 之前（`_run_loop`），检测本轮 `result.tool_calls` 中 name==`delegate_to_expert` 的数量：
  - > `_MAX_DELEGATE_PER_ROUND` 时，截断：只保留前 2 个 delegate 调用，多余的直接丢弃（不 append、不 dispatch），并追加一条中文 system 提醒：
    `已截断本轮多余的专家委派（单轮最多 {n} 次）。请串行委派或合并任务。`
  - 非 delegate 调用不受影响（只截 delegate）
- 实现：构造 `kept_tool_calls`（delegate 计数保留前 2，其余 tool_calls 全部保留——注意：截断只针对 delegate 超量，其他工具照常）
