# 第三轮优化 E8 实现计划：会话临时信息清洗

> 依据：`docs/superpowers/specs/2026-08-07-deerflow-borrow-design.md` E8。借鉴 DeerFlow `updater.py:179-213`（不持久化上传事件等会话临时物）。落盘 L3 前清洗"任务图文件名/URL/本次标注数据路径"等会话临时引用，只存可复用能力结论，防下次会话引用已失效文件。TDD。

## 现状（已核实）
- `store.append_learning_summary(text, ref)`（store.py:551）：把 write_learning_record 的 text 追加到 L3 recent.md「Learning Records」。text 由 Coach 生成，可能含 `annotation_tool.html`、`public/images/xxx.png`、`http://...`、`workspace/...` 等会话临时引用。

## 改动 `deeptutor/services/memory/store.py`
1. 新增模块级 `_SCRUB_PATTERNS: tuple[re.Pattern, ...]`：
   - URL：`https?://\S+`
   - 会话工具/资源路径：`/[\w/]*annotation_tool[\w.]*`、`/images/[\w./-]+`、`workspace/[\w./-]+`
   - 常见标注文件：`[\w./-]+\.(png|jpg|jpeg|html|jsonl)`（引用的文件名）
   - 任务临时标识：`task_id[:：]?\s*[\w-]+`
2. 模块级 `_scrub_session_noise(text: str) -> str`：依次用 patterns 替换为""，清理多余空格/顿号残留（`，`/`、` 连续 + 空），strip；空结果返回原文（兜底不吞内容）
3. `append_learning_summary`：`text = _scrub_session_noise(text)` 后再 append
4. 导出一致性：`__all__` 若存在则加 `_scrub_session_noise`（可选）

## 测试
- `tests/services/memory/`（新建 `test_scrub_session_noise.py` 或加到 test_bucket_paths）：
  - 含 URL + `/images/task1.png` + `annotation_tool.html` + `task_id: abc` 的文本 → 清洗后不含这些片段

  - append_learning_summary 集成：text 含临时物 → 落盘 L3 recent.md 的条目不含临时物（读回断言）
  - 空/极短文本 → 兜底返回原文
