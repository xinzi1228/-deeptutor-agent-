## 改动：`deeptutor/agents/chat/agent_loop.py` `_run_loop`
在循环体内（`_call_llm` 返回后、执行 tool_calls 前）插入检测：

1. 函数开头维护 `from collections import deque; recent_calls: deque[str] = deque(maxlen=20)`
2. 每轮有 `result.tool_calls` 时，对每个 tool_call 算指纹：
   ```python
   import hashlib, json as _json
   def _call_fingerprint(tc) -> str:
       args = tc.get("args") if isinstance(tc.get("args"), dict) else {}
       blob = _json.dumps([tc.get("name"), args], ensure_ascii=False, sort_keys=True)
       return hashlib.md5(blob.encode("utf-8")).hexdigest()
   ```
   （先看文件已有 import，复用）
3. 更新窗口：对每个指纹 `recent_calls.append(fp)`；`count = recent_calls.count(fp)`
4. **count >= 3**：向 `messages` 追加一条 system 提醒（仅当该提醒尚未在本轮出现过，避免刷屏；用函数局部 set 记录已提醒指纹）：
   ```
   {"role": "system", "content": f"警告：你已重复调用 {tool_name} 相同参数 {count} 次。停止重复，基于已有结果直接给出结论或换一种方式。"}
   ```
   （`tool_name = tc.get("name")`）
5. **count >= 5**：不执行本轮 tool_calls（跳过 dispatch），塞提醒后 `continue`（逼模型产出文本）；若持续重复直到 max_rounds 自然收敛。**注意有界**：max_rounds 兜底。
   - 实现：设置 `drop_tool_calls = count >= 5`；`if drop_tool_calls: messages.append(system 强提醒); continue`（在 :309 追加 assistant 之前）
   - 提醒文本区分档位：≥3"警告：停止重复"；≥5"已强制中断本轮工具调用，请直接输出结论"
6. `state` 加只读统计（可选，供 trace 审计）：`state.repeat_warnings`（计数器）——仅当 AgentLoopState 结构简单可加；若复杂则用局部变量并记录到 `logger.warning`。
