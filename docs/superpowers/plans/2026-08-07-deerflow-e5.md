# 第三轮优化 E5 实现计划：长会话上下文折叠 + 落盘义务重注入（MVP）

> 依据：`docs/superpowers/specs/2026-08-07-deerflow-borrow-design.md` E5。借鉴 DeerFlow SummarizationMiddleware（消息超阈值触发、保留最近 N 条、AI/Tool 对不拆）+ TodoMiddleware（关键义务被摘要挤出后重注入）。**MVP 不做 LLM 摘要调用**（教学场景省成本）：结构折叠——保留最近 K 轮完整对话，更早轮次压缩成一条 `[对话摘要]` system 占位 + 落盘义务重注入提醒。TDD。

## 现状（已核实 agent_loop.py）
- `_run_loop`（L268-432）：`for _round in range(max_rounds)`，messages 逐步累积（assistant + tool 消息），每轮 `checkpoint_boundary = self._fold_context_checkpoint(...)`（L429）
- `_fold_context_checkpoint`（L446-464）：仅当 dispatch 有 checkpoint summary 时把 `messages[:checkpoint_boundary]` 折叠成 `[Context checkpoint]` system
- **无对话级摘要**：长会话（45-60 分钟）消息无限增长

## 设计
新增 `_summarize_old_rounds(messages, *, keep_rounds) -> int`（返回新的 boundary）：
1. 从尾部向前扫描，找最近 `keep_rounds` 个完整轮次（一轮 = 1 条 assistant + 其后的 role=tool 消息们；以 assistant 消息为轮次起点，向前数 assistant 出现次数）。保护：不拆分 AI/Tool 对。
2. 若可压缩部分（messages[1:kept_start]）≥ 阈值（如 ≥30 条消息）才动作，否则原样返回。
3. 压缩：`compressed = [messages[0]] + [摘要 system 消息] + messages[kept_start:]`，摘要内容：
   ```
   [对话摘要]
   较早的 {n} 轮教学对话已压缩以节省上下文。若此前有教学里程碑（任务评分、反馈、诊断结论）尚未调用 write_learning_record 落盘，请立即补录，否则视为已记录。
   ```
4. 返回新 boundary = 摘要后 messages 中 kept_start 前的索引（即 2）。

触发：在 `_run_loop` 每轮 dispatch 后、`checkpoint_boundary` 更新处（L429 附近）调用：
```python
if len(messages) > _SUMMARY_TRIGGER_MESSAGES:
    checkpoint_boundary = self._summarize_old_rounds(messages, keep_rounds=_SUMMARY_KEEP_ROUNDS)
```
- 常量：`_SUMMARY_TRIGGER_MESSAGES = 80`、`_SUMMARY_KEEP_ROUNDS = 10`
- 只触发一次后可继续增长（保持简单：每次超阈值都尝试，但已压缩后旧区不重复压缩——由 kept_start 自然保证）
