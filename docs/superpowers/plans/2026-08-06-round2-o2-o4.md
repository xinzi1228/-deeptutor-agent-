```python
def _entry_sort_key(self, entry, md_mtime: float) -> tuple:
    """conf 主序 + recency 次序：同 confidence 新记忆优先。"""
    return (
        entry.confidence is None,
        -(entry.confidence or 0.0),

    )
```

### Task 2: O4 读记忆 30s 进程内缓存

**Files:**
- Modify: `deeptutor/services/memory/store.py`（读路径缓存）

- [ ] **Step 1: 加 TTL 缓存**——`read_bucket`（以及 fallback 变体）加进程内 30s TTL 缓存，key = `(bucket, fallback, overview_only)`，缓存值 = 返回字符串 + 时间戳。实现：

```python
import time as _time
from functools import lru_cache  # 不适合 TTL；用简单 dict + 时间戳

_READ_CACHE_TTL_S = 30.0
_read_cache: dict[tuple, tuple[float, str]] = {}

def _cached_read(key, producer):
    now = _time.monotonic()
    hit = _read_cache.get(key)
    if hit and now - hit[0] < _READ_CACHE_TTL_S:
        return hit[1]
    value = producer()
    _read_cache[key] = (now, value)
    return value
```

`read_bucket` 内部用 `_cached_read((bucket, fallback, False), lambda: self._read_bucket_uncached(...))`——把现有逻辑抽到 `_read_bucket_uncached` 或包裹。

- [ ] **Step 2: 失效点**——记忆写入（`write_entry`/`write_preference`/consolidator/`ops.py` 写操作）后需清缓存（`_read_cache.clear()`），否则缓存 30s 内看不到新记忆。**关键：读记忆是教学高频操作，写后立即读需看到新内容**。
