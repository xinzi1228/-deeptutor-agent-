# 标注工作区可靠性改造设计

## 目标

修复学习进度页内容截断、标注陪练与主聊天混用会话、陪练头像不可移动、Label Studio 入口 404，以及任务库未完整接入自建标注台的问题。

## 方案

### 1. 学习进度页滚动

进度页的根容器改为在应用主内容区内纵向滚动，保留现有标题、分页签和图表结构。页面不再依赖固定可视高度，鼠标滚轮可浏览全部统计卡、报告、图谱和扩展内容。

### 2. 标注陪练独立会话与可拖动入口

`AnnotationCoach` 不再读取主聊天的 active session，而是在浏览器本地生成并保存单独的标注陪练 session id。该 id 使用 `annotation-coach-` 前缀，标注陪练消息只进入该会话。

陪练入口改为受边界限制的悬浮拖拽控件：拖动发生在头像按钮上，点击未产生明显移动时仍打开/关闭对话框；松开后将位置保存到 localStorage，避免拖出可视区域。

### 3. Label Studio 专业模式

前端不将 Label Studio 失败直接表现为空白 iframe。专业模式先检查 `http://127.0.0.1:8080` 是否可用；可用时用该地址嵌入并提供“新窗口打开”，不可用时展示启动说明。项目内涉及 Label Studio 的链接统一使用同一常量，避免 `localhost` 在 IPv6 环境下失效。

### 4. 任务库接入自建标注台

新增只读任务库 API，按 `task_bank.json` 返回任务摘要和单条任务。标注页上增加任务选择器；根据任务类型将选中任务通过 iframe `postMessage` 发给自建图片、文本、音频或视频标注台。自建台加载任务素材、类别、参考答案和 AI 预标注，提交时将 `task_id`、预测结果、标准答案发送至已有 `/api/v1/annotation/check` 评分接口。

## 错误与安全边界

- 会话 id 只保存为浏览器状态；后端继续依照当前用户身份隔离数据。
- 任务 API 不接受任意文件路径或外部 URL；只读取当前用户工作区的任务银行。
- Label Studio 保持管理员配置的外部工具性质，不开放学生传入命令或服务器地址。
- iframe 消息严格校验消息类型、任务类型和数据对象，未知消息被忽略。

## 验收与测试

- 前端类型检查通过；进度页内容可滚动。
- 陪练首次生成独立会话、刷新后保持；拖拽位置不越界。
- Label Studio 不可用时展示可读错误；可用时正确嵌入。
- 任务 API 与任务选择/评分流程有后端测试或组件级验证。
