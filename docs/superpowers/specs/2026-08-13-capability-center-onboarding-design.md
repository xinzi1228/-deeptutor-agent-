# 一站式初始化、能力中心与资料导入设计

日期：2026-08-13
状态：已由用户逐节确认，待实施计划

## 1. 目标

把当前分散在多个技术设置页的知识库导入、模型、Skill、MCP、学习插件、Label Studio 和系统状态，整理成新手也能完成的一站式初始化与日常管理体验。

默认界面使用教学语言描述“能做什么、缺什么、怎样修复”，技术参数收进高级设置。

## 2. 权限分层

- **教师/管理员**：配置模型与密钥、导入公共知识库、管理扩展来源、配置 Label Studio、查看系统体检。
- **普通学生**：使用管理员配置好的能力，可以安装或启用被批准的学习插件，不能填写任意 MCP 地址、命令或模型密钥。
- **学习档案**：选择管理员允许的知识库和学习插件，不改变账号级系统配置。

密钥、Token、PIN 和隐藏账号信息不得进入学生页面、诊断报告或大模型上下文。

## 3. 首次初始化向导

管理员首次登录按以下顺序完成：

1. 检测运行环境和必要服务。
2. 配置主对话模型。
3. 可选配置生图、Embedding、语音和视频模型。
4. 导入第一份知识库并完成解析、索引与引用测试。
5. 从审核市场启用 Skill、MCP 或学习插件。
6. 创建学生学习档案。
7. 运行完整健康检查。

可选步骤允许跳过。每一步必须说明“暂时不配置会缺少什么、哪些核心功能仍可使用”。向导可中断并从上次步骤继续。

## 4. 统一能力中心

```text
能力中心
├── 模型能力：对话、生图、Embedding、语音、视频
├── 知识与资料：导入、解析、索引、失败处理、引用测试
├── 扩展市场：Skill、MCP、学习插件
├── 标注服务：Label Studio、数据同步、标注教练
└── 系统体检：账号、服务、存储、模型、权限
```

现有技术设置页继续保留，并统一收进“高级配置”。能力中心卡片显示当前状态、用途、影响范围和主要操作。

## 5. 知识库导入

默认流程：

```text
拖入文件或文件夹
→ 自动识别格式与解析方式
→ 显示文件清单、重复项和预计处理方式
→ 开始导入
→ 展示解析、切分、索引进度
→ 用示例问题验证答案及引用
```

解析器、切分参数、Embedding 模型等选项默认折叠到“高级选项”。

### 5.1 可恢复任务

导入任务保存阶段、文件状态、解析版本和重试信息。页面关闭、服务重启或部分文件失败后可以继续；成功文件不会因个别失败回滚。

### 5.2 修复卡

- 重复文件：展示已有版本，选择跳过、替换或保留新版。
- 扫描 PDF：建议 OCR/文档解析器并允许一键重试。
- 解析内容过少：并排显示原文预览和解析预览。
- Embedding 未配置：跳转配置，完成后回到当前步骤继续。
- 部分失败：成功项继续，失败项进入待处理列表。
- 任务中断：保存进度，下次继续。

完成后必须执行一次引用测试，确认回答能够指向正确资料；失败时提供可操作建议，不用堆叠底层异常。

## 6. 扩展市场

界面统一展示三种扩展，后台仍保持不同实现与权限：

- **Skill**：提示规范、知识和工作流程。
- **MCP**：外部工具及数据服务连接。
- **学习插件**：学习路径图、专项练习等产品功能。

扩展卡显示用途、适用人群、权限、额外费用、配置要求、健康状态、安装/启用/停用/测试按钮。

### 6.1 来源安全

- 默认安全模式只允许审核白名单和已审计本地包。
- 普通学生只能看到管理员审核上架的扩展。
- 管理员显式开启开发者模式后才能添加 GitHub、命令或网络 URL 等自定义来源。
- 自定义扩展启用前展示文件、网络、命令和数据访问权限，并通过安全检查与测试沙箱。
- 安装、升级、授权和停用均记录审计事件。

## 7. 模型配置

默认流程：

```text
选择提供商
→ 填写 API Key 或完成 OAuth
→ 自动获取模型
→ 选择用途
→ 连通性与能力测试
→ 设置默认模型
```

系统显示“可以聊天、可以看图、可以生图、可以 Embedding”等能力标签。Base URL、温度、上下文长度等放入高级选项。

- 对话、生图、Embedding、语音和视频可分别选择默认模型。
- 多个生图模型可设置一个默认模型，单次生成前允许临时切换。
- API Key 保存后只显示掩码，不提供明文回显。
- 用户没有配置某项模型时，调用方应跳转到对应配置卡，而不是给出模糊报错。

## 8. 标注服务卡

集中显示：

- Label Studio 服务状态与版本；
- 学生专业模式统一进入能力；
- 任务和结果同步队列；
- 标注教练上下文连接状态；
- 直接修复或重新检测入口。

Label Studio 中文化不属于本期目标。

## 9. 一键体检

体检采用三类用户状态：

- **正常**：当前可以使用。
- **受限**：核心功能可用，但缺少某项可选能力。
- **故障**：对应功能不可用。

每项提供大白话说明、影响范围、“去修复”和“重新检测”。支持下载脱敏诊断报告，报告不得包含 API Key、PIN、Token、Cookie 或隐藏 Label Studio 身份凭证。

## 10. 复用与迁移

- 复用现有设置 API、ServiceConfigEditor、MCP 管理、知识库任务和受控学习扩展市场。
- 新能力中心先作为聚合与引导层，不立即删除原设置页面。
- 新手路径只展示必要字段；高级设置继续服务开发和运维。
- 统一状态协议，避免每张卡自行判断“已配置”与“可用”。

## 11. 验收标准

- 新管理员可以不阅读命令行文档完成主模型配置、导入资料和引用测试。
- 可选能力跳过时明确显示影响，不阻止核心系统启动。
- 部分知识文件失败后成功文件仍可使用，失败文件可单独修复重试。
- 学生无法访问模型密钥、任意 MCP 来源或管理员高级配置。
- 未审核的自定义扩展不能绕过测试直接启用。
- 一键体检可区分正常、受限和故障，并提供正确修复入口。
- 脱敏报告不包含任何秘密值。

## 12. 非目标

- 本期不取消全部高级设置页。
- 本期不允许学生安装任意网络来源。
- 本期不把 Skill、MCP 和学习插件合并为同一种后台实现。
