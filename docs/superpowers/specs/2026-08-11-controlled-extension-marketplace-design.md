# 受控插件市场与学习路径图设计

## 目标

在不允许用户执行任意外部命令、读取其他学生数据或安装未审核软件的前提下，让每位学生可以从平台市场安装并启用自己的 Skill/MCP 扩展。第一批插件包含“学习路径图”和“学习报告增强”。

## 范围

- 管理员维护审核后的插件目录；学生只可安装、启用、停用目录中的插件。
- 用户安装记录独立保存；模型只接收当前用户已启用的扩展。
- 学习路径图基于当前用户的课程计划、学习记录和确认易错点生成；采用 Excalidraw Diagram Generator 的认知负荷和可访问性规范。
- 不允许学生输入 GitHub 地址、npm 包名、MCP 命令或环境变量。
- 不复制外部 AGPL 代码；Excalidraw MCP 只作为受控平台依赖使用。

## 数据模型

### 插件目录

每个条目包含 `id`、`name`、`description`、`kind`（skill/mcp/visualization）、`version`、`permissions`、`published`、`entrypoint` 和 `allowed_tools`。目录由管理员维护，客户端只读。

### 用户安装清单

每个用户保存 `plugin_id`、`enabled`、`installed_at`、`consented_permissions` 和最近错误摘要。安装只保存配置，不复制或执行第三方代码。

## 调用网关

1. 对话开始时读取当前用户安装清单。
2. 只将 `published && enabled` 的条目解析为可用能力。
3. 每次模型调用前再次检查插件、用户、允许工具和资源 scope。
4. 未安装、下架、停用、越权或权限不匹配时拒绝调用，并写入审计日志。
5. 插件没有任意 shell、删除文件、跨用户读取或密钥读取权限；涉及网络或学习记录写入需在安装时明确展示。

## 学习路径图插件

- 输入仅为当前学生课程计划、学习记录、确认易错点和下一任务。
- 输出为受限图形描述或 Excalidraw JSON，不含服务器路径、其他用户信息或原始私密对话。
- 每张图最多 9 个核心节点、总文字不超过 50 词、固定高对比安全配色，颜色不作为唯一信息载体。
- 一图只说明当前学习路径：已掌握、正在学习、待巩固、下一步。
- 无课程或学习数据时显示诚实的空状态，不生成虚构节点。

## 页面

- 学生“扩展市场”：浏览、查看权限、安装/启用/停用。
- 学生个人中心：仅在启用路径图插件后显示学习路径图。
- 管理员扩展管理：上架、下架和查看使用审计；下架后立即阻断新调用。

## 初始插件

1. `learning-path-diagram`：可视化当前学习路径，只读学习数据。
2. `report-card-enhancer`：把现有可信学习报告整理为短卡片，只读学习数据。

## 测试与验收

- 两位学生安装不同插件时，可调用能力不同。
- 未安装、停用或下架插件均不可调用。
- 任何路径图只能读取当前用户数据，且满足节点、文本和配色限制。
- 安装确认准确展示权限；审计日志不记录敏感原文。
- 既有 MCP 设置页和对话工具不因市场功能失效。
