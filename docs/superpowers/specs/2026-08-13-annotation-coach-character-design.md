# 标注教练“星轨机器人”品牌形象设计

日期：2026-08-13
状态：角色方向与生产规格已确认，待 Image2 生成

## 1. 用途

为标注星图的固定标注教练建立独立、可识别、可扩展的品牌角色，用于教学模式与 Label Studio 专业模式中的悬浮头像、对话面板、提示气泡、空状态和宣传材料。

该固定角色由 Image2 生成，与产品运行时用户自行配置的生图模型完全分开。

## 2. 已选视觉方向

用户在视觉伴随页中确认：

- 角色类型：A“星轨机器人”；
- 美术风格：A“软萌 3D”。

未采用星星精灵和人形数字导师；未采用扁平矢量或偏二次元的最终母版风格。

## 3. 角色母版规格

- 软萌 3D 小机器人，头大身小，造型圆润。
- 蓝色到紫色渐变，继承现有标注星图品牌色。
- 头顶有发光星星天线，呼应品牌星图与星轨。
- 胸前是虚线标注框和四个控制点。
- 手持数位标注笔，明确表达数据标注身份。
- 眼神友好、聪明、耐心；不幼稚，也不严肃。
- 材质为柔和的高品质智能硬件与轻微磨砂塑料质感，避免强金属反射。
- 正面偏三分之二角度，角色完整、轮廓清楚，缩小后仍可识别。
- 不在图片中生成中文、英文、数字、Logo 或水印。
- 避免复杂背景、额外人物、真实品牌标志和过多装饰。

## 4. 生产流程

1. 使用 Image2 生成标准母版候选图。
2. 检查角色结构、星星天线、标注框、数位笔和品牌色。
3. 用户确认母版后，生成纯色键控背景版本并制作透明 PNG。
4. 验证透明边缘、缩略图识别度和深浅色界面适配。
5. 从同一母版衍生状态图，不随意改变角色结构或颜色。

母版未确认前，不直接替换项目现有 `🤖` 头像。

## 5. 状态资产

母版确认后制作：

- 默认：平静、友好；
- 思考：专注分析；
- 鼓励：轻微挥手或点赞；
- 提醒：举起提示牌或发光星星；
- 成功：开心庆祝；
- 错误：关切但不沮丧。

不同状态必须保持相同头身比例、面部结构、色彩、星星天线、胸前标注框和数位笔设计。

## 6. 项目资产建议

最终资产放入 `web/public/coach/`，采用稳定英文文件名：

- `coach-master.png`：母版透明图；
- `coach-default.png`；
- `coach-thinking.png`；
- `coach-encourage.png`；
- `coach-reminder.png`；
- `coach-success.png`；
- `coach-error.png`。

同时导出至少 64、128、256 和 512 像素规格或使用高分辨率母版按需缩放。前端保持替代文本，动画应尊重 `prefers-reduced-motion`。

## 7. 前端应用

- 关闭状态：使用小尺寸默认头像，保留现有拖动能力。
- 发送中：显示思考状态，不依赖持续高耗动画。
- 主动提醒：显示提醒状态并短暂高亮。
- 回合成功或任务完成：短时显示成功或鼓励状态。
- 调用错误：使用关切状态，文案仍保持清楚专业。
- 教学模式与专业模式使用同一角色资产和状态机。

## 8. 验收标准

- 64 像素下能识别星星天线、脸部和蓝紫主体。
- 母版中明确包含标注框与数位笔元素。
- 没有乱码、品牌侵权元素、水印或复杂背景。
- 角色与现有标注星图 Logo 在色彩和主题上协调，但不直接复制 Logo。
- 透明图边缘无明显纯色毛边，在浅色和深色界面上均清楚。
- 各状态保持同一角色身份，不出现结构漂移。

## 9. 非目标

- 本设计不生成新的项目 Logo。
- 本设计不决定用户对话中的生图模型。
- 本设计不在母版阶段制作复杂动画或 3D 模型文件。
