# 「标注星图」演示脚本（向指导老师展示）

> 日期：2026-08-15。竞赛黄金演示脚本见 `docs/competition/golden-demo-script.md`（5–7 分钟）；本文件是面向指导老师的完整展示版。
> **核心**：所有对话功能已提前跑成真实会话存在项目里，侧边栏点击即展示，无需现场打字。

## 准备（演示前 5 分钟）

1. 确认服务在跑：`start_all.bat`（后端 8001 + 前端 3782，可选 Label Studio 8080）
2. 浏览器打开 `http://127.0.0.1:3782`
3. 学生界面一级入口固定为「学习 / 实训 / 成长 / 我的」；管理员入口在侧边栏底部「管理员」

## 第一幕 · 这是"什么"——完整教学闭环（15 分钟）

> 侧边栏点击 **①完整教学闭环：诊断→AI预标注→评分→卡点介入**

| 滚动到 | 讲什么 | 背后技术 |
|--------|--------|---------|
| 开头问候 | Coach 记住学生（提到之前 task1 F1=50%） | 记忆系统 + 个性化 |
| 平台介绍 | 22 任务、三模态、5 维能力、职业对标 | 任务库 + 能力树 |
| 诊断建课 | 基于历史记录做诊断 → 生成 4 模块学习计划 | 知识图谱风险链 + finalize_diagnosis |
| 苏格拉底问答 | Coach 先问"画框最关键是什么"，再讲遮挡规则 | retrieve-first + 渐进提示 |
| **AI 预标注任务** | 任务卡："打开标注任务" + 标注台跳转 | AI 预标注审阅（竞赛创新点） |

## 第二幕 · 亮点展示（15 分钟）

### ②专家委派：评测专家+卡点侦探联合诊断
- 展示：提交标注 → 消息流出现"专家协作看板"（工作中→完成）→ 评测专家逐框分析 + 卡点侦探前置技能诊断 → 一致判定 review_first
- **讲**：多 Agent 架构——6 个专家各管一摊，上下文隔离不污染；专家看板实时状态

### ③能力评估：五维雷达+进度图表
- 展示：五维能力雷达 + 17 节点能力图谱（已掌握/挣扎/未开始）+ 自适应建议
- **讲**：能力树 + 知识图谱 + 数据驱动个性化

### ⑤AI预标注审阅：找错→修正→双评闭环
- 展示：Coach 基于卡点出 find_error 预标注任务 → 学生找错修正 → 双评（AI F1 vs 学生 F1）
- **讲**：**这是竞赛创新点**——真实标注工作里 AI 先标、人来质检；我们做成教学：预标对了练审阅，预标错了练找错

### ⑨交互练习卡：quiz_card 生成式UI
- 展示：可点击选项的练习题卡，点选即时对错反馈
- **讲**：生成式 UI——AI 不只是打字，能"画"出交互卡片（AG-UI 协议）

### ⑥陪伴教学：情绪支持+数据鼓励
- 展示：学生说"想放弃" → Coach 用真实进步数据（50%→100%）鼓励 + 共情 + 收尾一个小问题
- **讲**：陪伴人格 + 数据驱动（不是空泛鼓励，是拿你真实成绩说话）

### ④知识库检索+引用溯源
- 展示：回答带 `〔规范: bbox-guide§遮挡目标处理〕` 可点击引用
- **讲**：RAG 知识库（60 篇）+ 溯源三标注——AI 说的每句话有出处，不瞎编

- **知识库 50+**：强调 annotation_kb 60 篇 + 溯源
