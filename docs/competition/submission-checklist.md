# 竞赛提交清单（标注星图）

提交前逐项核对；任何一项未完成都应如实标注"受限/未完成"，不得隐藏。

## A. 产品能力

- [ ] 学生主路径连续：诊断 → 学习规则 → 矩形框标注 → 评分 → 订正 → 成长报告。
- [ ] 教学标注台与专业模式共享任务、正式结果、评分、记忆和教练上下文。
- [ ] 学生四入口生效：学习、实训、成长、我的；技术配置不出现在学生页面。
- [ ] 教师工作台只读；代管带理由、限时、留痕，不修改原始证据。
- [ ] 管理员五中心可用：内容治理、教学配置、AI 能力、扩展与集成、系统运维。
- [ ] 初始化向导可跳过、恢复、重测；重启从最后未完成项继续。

## B. 可信与安全

- [ ] 数字图表绑定服务端 `dataset_ref` 与哈希；未配置 Embedding/生图时显示受限，不伪造 ready。
- [ ] 对话、检索、图表和报告均能追溯到真实记录或已审核内容。
- [ ] 内容发布、评分规则变更需人工审核；AI 只能写候选修订。
- [ ] 密钥、PIN、Token、Cookie 不出现在接口、日志或提交。
- [ ] 学生、教师、管理员及代管权限矩阵通过；越权 URL 返回明确拒绝。
- [ ] 扩展市场白名单执行；学生不能创建/导入/任意执行工具；未审核扩展默认禁用。

## C. 真实用户证据

- [ ] 2 名学生（S01、S02）和 1 名职教教师（T01）完成优化前后两轮测试。
- [ ] 知情同意完整记录；录屏/录音/引用授权可核验；删除请求可执行并重算报告。
- [ ] 报告数字与原始事件记录、人工修订历史逐条可回查。
- [ ] 严重问题有关联修复提交与复测结论。
- [ ] 匿名证据包通过人工复核；姓名/学号/学校/人脸不进入默认包。

## D. 演示与性能

- [ ] 黄金演示 5–7 分钟连续三次通过。
- [ ] 冷启动 3 秒内可操作；页面切换 1 秒内出现核心内容；成长首屏 2 秒内完成。
- [ ] 发送后 300 毫秒内出现真实状态；模型正常时 5 秒内首字；超时可取消且不重复写入。
- [ ] 控制台无 `Canvas is already in use`。

## E. 外部依赖说明

- [ ] Embedding 五项验收、生图真实付费调用、Label Studio 契约在目标环境确认。
- [ ] 文档与实际产品一致；已知限制如实标注。

## F. 最终判断

只有当"专业内容可信、学生主路径连续、教学和专业模式共享事实、AI 输出有来源和预算、权限不可绕过、三名真实用户证据完整、竞赛电脑连续三次完成黄金演示，且文档准确说明外部依赖与已知限制"同时成立，才可宣布本轮完成。
