# 不能现场展示的功能（大白话说明）

> 这些功能项目里**已经做好了**，但演示当天不方便现场操作。不是没有，是展示条件限制。
> 每一项都写了"为什么不能展示"和"怎么补展示"。

---

## 1. Label Studio 专业模式（专业标注工具）

**是什么**：对接了一个业界成熟的开源标注工具（Label Studio），学生练熟了可以切过去用"专业模式"做更复杂的标注。学生通过标注星图的同源网关进入被分配的项目与任务，不需要、也不应该看到或输入 Label Studio 独立账号。

**为什么不能现场展示**：
- 它要单独启动一个服务（端口 8080），演示前如果忘了启动就打不开
- 需要管理员先配置服务 Token/桥接密钥、建项目、导入图片，准备流程长
- 它是独立页面，演示时要在多个窗口切换

**怎么补展示**：
- 如果时间够：演示前先跑 `start_label_studio.bat`，配置好 `LABEL_STUDIO_URL` 后，到"实训"页点"专业模式"，经同源网关即可进入（无第二次登录）
- 如果没时间：一句话带过——"平台对接了业界标准工具 Label Studio，新手用自建教学台，进阶可切专业模式；学生从标注星图进入，不接触 LS 账号"

## 2. 语音功能（语音对话/朗读）

**是什么**：可以让 AI 读文字（TTS）、学生说话（STT）。项目里"朗读"按钮就有，但完整语音 Agent 需要外部语音服务。

**为什么不能现场展示**：
- TTS/STT 服务没配置（模型列表里是空的）
- 语音需要外部 API key 和网络，现场可能不稳定

**怎么补展示**：
- 消息右上角有"朗读"按钮可以点，能读出来（如果浏览器支持）
- 主要讲设计思路："语音是未来扩展，当前专注教学核心"

## 3. 定时学习提醒（到点提醒）

**是什么**：让 Coach 定时提醒学生"该练标注了"（比如 30 秒后、每天 9 点）。

**为什么不能现场展示**：
- 提醒要**等到设定的时间**才触发，演示现场等不起
- 后台有定时任务管理页能看到注册的任务，但"到点弹提醒"要看运气

**怎么补展示**：
- 到"定时任务"页面，展示已注册的提醒任务列表 + 启停按钮
- 如果真想演示触发：演示前设一个 30 秒的提醒，聊天窗口保持打开，等 30 秒能看到 Coach 主动发消息

## 4. 四模态标注台的"亲手操作"（画框/标实体）

**是什么**：学生在统一 React 标注台上亲手画框、标文字、切音频。这是教学的核心交互。

**为什么不能现场展示（指让老师亲手玩）**：
- 需要真人操作鼠标在 Canvas 上画框，演示时如果让老师玩会拖时间
- 如果老师想试，可以现场让他画一个

**怎么补展示**：
- 演示脚本里已经用预跑好的会话展示了"标注结果 + 评分"的完整效果
- 到"实训"页，展示统一标注台的界面（不用操作，看一眼）

## 5. 生成式 UI 练习卡的"现场点击"

**是什么**：AI 出可点击的练习题卡，点选项即时对错。

**为什么不能现场展示**：
- 不是不能，是要看 Coach 出题时机（已经在会话⑨里预跑好了）

**怎么补展示**：
- 点开会话⑨，练习卡就在那里，现场点选项就能看到对错反馈

## 6. 上游 DeepTutor 的通用功能（已裁剪）

**是什么**：原框架自带的一些通用功能（深度研究、数学可视化、伙伴系统等）。

**为什么不能展示**：
- 已经被裁剪掉了——这个平台专注"数据标注教学"，那些通用功能会让学生迷路
- 这不是缺陷，是刻意设计：**只留教学主线**

## 7. 免登录分享（如果老师现场要看链接）

**是什么**：把会话打包成链接发给别人看，不用登录。

**为什么"可能"不能展示**：
- 生成链接要点击"分享"按钮（在会话右上角），演示时点一下就行——这个**可以展示**
- 但如果老师现场没有网/打不开外链，就看不了

**怎么补展示**：
- 演示时先生成一个分享链接，复制到浏览器打开，展示"免登录可看"

---

## 一句话总结

**项目 95% 的功能都能现场演示**（9 条预跑会话 + 4 个页面）。上面 7 项是"展示条件限制"（服务没启/要等时间/要真人操作），不是功能缺失。每一项都有替代展示方案，正常演示完全够用。
