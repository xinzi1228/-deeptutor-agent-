# 我们给 DeepTutor 加了什么？（大白话版）

> 这份是给人看的通俗版。技术版在 `docs/fork-features.md`。
> 一句话总结：**我们把这个通用 AI 助教，变成了一所「数据标注培训学校」——有老师、有作业、有成绩单、有毕业标准，还能记住每个学生的进步。**

---

## 一、打开浏览器就能看到的（不用做任何操作）

启动后打开 **http://localhost:3782**，左侧菜单多了三样东西。

### 1. 个人中心 = 「学生的成绩单 + 老师的工作报告」

点左侧 **Progress**（个人中心），从上往下能看到 10 个板块：

| 板块 | 大白话解释 |
|------|-----------|
| 统计卡片 | 学得咋样：最新分数、任务通过几个、会几个知识点 |
| 教练绩效 | 老师干得好不好：学生进步了多少、老师猜学生下一步猜得准不准 |
| 五维雷达 | 用雷达图看 5 项能力：画框准不准/认标签准不准/漏没漏/稳不稳/懂不懂 |
| 能力图谱 | 一张技能树，29 个技能哪些打勾（学会了）哪些灰（还没学） |
| F1 成长曲线 | 学生每次练习的分数折线，看是不是越练越好 |
| **知识图谱·风险链**（新加的） | 像「技能地图 + 交通警示」：哪些技能没打地基、哪个技能学不好会连累后面哪个任务 |
| 教学决策 | 老师每次推荐作业、判断能不能过关，都会写一句"为什么" |
| 课程计划 | 4 个学习模块的路线图，还能**下载成 Word 手册** |
| 方案评估 | 一个"挑刺的检查员"看老师的教学方案，提出质疑和改进建议 |
| 时间线 | 按日期排的学生学习流水账 |

> 右上角有个 **记忆整理** 按钮——点一下，系统把重复的记忆合并、归档，就像整理抽屉。

### 2. 标注工作台 = 「学生做作业的地方」

点左侧 **Annotation**（数据标注）：

- **基础模式**：一个画框小工具，8 个真实任务（找车/找马/分类等）。学生拖鼠标画框 → 点「检查标注」→ 立刻出分数（准不准/漏没漏）→ 点「问Coach」就把结果发给老师分析。
- **专业模式**：嵌入了真正的工业级标注工具 **Label Studio**（已启动，http://localhost:8080），展示"学会用真工具"。

### 3. 记忆中心 = 「学生的小本本」

点左侧 **Memory**（记忆）：

- 三层记忆：**最近发生的事**（L1）→ **每周小结**（L2）→ **长期档案**（L3：学生是谁、喜欢什么、学过什么）
- **记忆图谱**：一圈一圈的同心圆，越往里越是长期记忆，能缩放拖拽。

## 二、要先跟"老师"对话，才出现的功能

在 **Home** 页面选 **annotation-coach**（标注教练）这个老师，然后：

| 你（学生）说 | 会发生什么 |
|-------------|-----------|
| "我是零基础，想学标注找工作" | 老师开始**诊断**：问背景、摸底、给你定学习路线 |
| 老师问完诊断问题后 | 自动**建课程计划** + 记下你的档案（下次来还记得你） |
| "讲一下 IOU（重叠度）" | 老师调出一个**能拖动的图**演示，边看边讲 |
| "这个任务有风险吗？" | 老师查**知识图谱**，告诉你"这个技能你地基没打好，会连累后面" |
| 你提交作业（框） | 老师**自动打分**（F1 分数）+ 记录成绩 + 判断你能不能过关 |
| 老师推荐作业/判定过关 | 都会写一句**"为什么"**（决策审计） |

> 这些对话我**已经帮你预跑过一遍**（6 回合真实对话），所以成绩单和知识图谱现在有真实数据，打开就能看。

### 不想开浏览器？用命令行也能看

```
python -m deeptutor_cli.main chat -l zh -p annotation-coach
```
进去后输入：
- `/progress` —— 看学习进度仪表盘
- `/concept-map` —— 看能力图谱掌握状态
- `/challenge` —— 让老师出一道迁移挑战题

## 三、看不见、但默默干活的部分（后台）

这些没有界面，但支撑着上面所有功能：

| 后台能力 | 大白话解释 |
|---------|-----------|
| **学习记录库** | 每次对话/练习/成绩都存成记录，是所有面板的数据来源 |
| **知识图谱引擎** | 自动把"技能依赖关系 + 学生掌握情况"织成一张图，供老师查询风险链 |
| **记忆演化** | 定期自动整理记忆：合并重复的、归档旧的、提炼长期档案 |
| **教学自改进** | 如果学生成绩停滞，老师会自动改自己的教法并记录"改了啥、为啥" |
| **课程引擎** | 根据诊断结果，自动生成 4 模块课程 + Word 手册 |
| **MCP 接口** | 一个标准接口，外部 AI 工具（如 Claude Code）也能查学生学习情况 |
| **15 个 API** | 前端所有面板的数据通道 |

## 四、5 分钟演示脚本（照着讲就行）

**开场白（30 秒）**：
"我们把这套系统做成了一个'数据标注培训学校'：有智能老师、有作业、有成绩单，还配备了工业级标注工具。"

**第 1 步（1 分钟）· 看成绩单**：
打开 **Progress 页**，指着 F1 曲线说"学生每次练习的分数"，再指知识图谱说"这是技能地图，红色=有风险的技能，缺地基会连累后面的任务"。

**第 2 步（1 分钟）· 看老师怎么教学**：
到 **Home** 跟老师对话，说"我想继续学习"，展示老师能记住上次学到哪、接着教。

**第 3 步（1 分钟）· 演示做作业**：
到 **Annotation 页**，选任务 → 拖个框 → 点"检查标注" → 看分数 → 点"问Coach" → 老师分析。

**第 4 步（1 分钟）· 展示真工具**：
Annotation 切 **专业模式**，展示内嵌的 Label Studio（工业级标注软件）。

**第 5 步（30 秒）· 记忆**：
点 **Memory**，展示三层记忆 + 记忆图谱，"系统能记住学生的长期档案"。

## 附：常用名词翻译表

| 术语 | 大白话 |
|------|--------|
| F1 分数 | 综合评分（画框准不准 + 漏没漏，满分 1） |
| IOU | 两个框重叠程度（重叠面积 ÷ 总面积） |
| 知识图谱 | 技能的"地图 + 依赖关系网" |
| 风险链 | "这个没学会，连累后面学那个"的链条 |
| 决策审计 | 老师每次判断都写"为什么"的记录 |
| 记忆整理（Reflection） | 自动把重复/旧的记忆合并归档 |
| MCP | 让外部 AI 程序也能访问学习数据的标准接口 |
| 能力树 | 29 个标注技能的树状清单 |
| 课程计划 | 4 个模块的学习路线 + Word 手册 |
