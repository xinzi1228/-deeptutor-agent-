# Phase 0: 迎新与诊断 — 设计文档

## 概述

学生首次进入平台，选择 annotation-coach Persona 后，
Coach 自动执行迎新与诊断流程，确定学生的学习起点。

---

## 进入判断流程

```
学生进入 → Coach 调 read_memory
  │
  ├─ 有历史记录？
  │   ├─ 是 → 展示进度摘要 + Mini雷达图
  │   │       "你上次学到 task3，F1 85%。要继续还是复习？"
  │   └─ 否 → 进入诊断流程
  │
  └─ 诊断流程（混合式：闲聊 + 测验）
        │
        ├─ Step 1：闲聊了解背景（2-3 轮对话）
        │   Q1: "你之前接触过数据标注吗？"
        │   Q2: "如果做过，说说你做的是什么类型的标注？"
        │   Q3: "有没有遇到让你困惑的情况？"
        │
        ├─ Step 2：摸底测验（2-3 题）
        │   实操题：展示一张图片，"这张图里有哪些需要标注的物体？"
        │   概念题：判断题 "IOU=0.5 表示两个框重叠了一半，对吗？"
        │   格式题："如果要画一个框，坐标信息应该怎么表达？"
        │
        └─ Step 3：综合判断
            ├─ 完全新手          → 理论 §1.1 + 实践 task1(easy)
            ├─ 有概念但没做过    → 跳理论，从 task1(easy) 开始
            ├─ 做过但不熟        → 从 task3(medium) 摸底
            └─ 老手              → 直接 task6(hard) 摸底
                  └─ 摸底不理想  → 弹出"建议回基础巩固"选项

## 自我介绍 + 学习全景

### 对话中展示

Coach 输出：
1. 一句简短自我介绍
2. 一张 Mini 能力地图（用 code_execution 生成 400x200 图片）
3. 一句话引导："看到左侧「个人中心」随时查看学习进度 →"

### 个人中心页面

新增侧边栏入口：「个人中心 / 我的学习」

包含三个图表模块：
| 图表 | 类型 | 内容 |
|------|------|------|
| 能力雷达图 | 雷达图 | 4 领域掌握度（图像/文本/质量/工具） |
| 技能树 | 树状图 | 29 个技能节点，颜色标记已掌握/学习中/未开始 |
| F1 成长曲线 | 折线图 | 每次练习的 F1 分数随日期变化 |

图表库：ECharts 或 Chart.js（后续调研决定）

## 记忆格式

评测后 write_memory 使用结构化 JSON：

```json
{
  "type": "annotation_exercise",
  "task_id": "task2",
  "f1": 0.85,
  "precision": 0.90,
  "recall": 0.81,
  "difficulty": "medium",
  "knowledge_points": ["多目标检测", "小目标标注"],
  "timestamp": "2026-07-31T10:00:00"
}
```

## Coach 使用的工具

| 步骤 | 工具 | 作用 |
|------|------|------|
| 进入判断 | read_memory | 读取历史记录 |
| 学习全景 | competency_map action=overview | 获取能力树 |
| Mini 雷达图 | code_execution | 跑 Python 生成图片 |
| 摸底测验 | get_annotation_task | 给老手发 hard 任务 |
| 摸底评测 | annotation_check | 检查老手水平 |
| 记录结果 | write_memory | 存入结构化 JSON |

## 验收标准

- [ ] 新用户进入后，Coach 自动执行诊断流程（闲聊 2-3 轮 + 测验 2-3 题）
- [ ] 有历史的用户，Coach 展示上次进度 + Mini 雷达图 + "继续/复习"选项
- [ ] 老手摸底不理想时，Coach 提供"回基础巩固"选项
- [ ] 个人中心页面可访问，包含雷达图、技能树、F1 曲线
- [ ] 记忆格式为结构化 JSON
