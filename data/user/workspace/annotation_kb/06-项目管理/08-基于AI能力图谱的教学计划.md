# 基于 AI 能力图谱的教学计划设计

## 设计理念

本教学计划以"AI 数据标注工程师"岗位的能力图谱为导向，按照从基础认知到独立执业的递进层级设计课程体系。每个层级包含理论教学和实操训练两部分，总课时约 46 课时（45 分钟/课时）。

## 能力图谱与课程映射

### 层级 0：基础认知（2 课时）

**能力目标：** 理解数据标注在 AI 产业链中的位置和价值

| 课时 | 教学内容 | 教学方式 |
|------|---------|---------|
| 第 1 课 | 人工智能发展简史与数据标注的关系 | 讲座 + 视频 |
| 第 2 课 | 认识主流标注类型（分类/检测/分割/NER/关键点/跟踪） | 讲座 + 案例展示 |

### 层级 1：工具操作（8 课时）

**能力目标：** 熟练使用 Label Studio 和 CVAT 完成基础标注任务

| 课时 | 教学内容 | 教学方式 |
|------|---------|---------|
| 第 3 课 | Label Studio 安装配置与项目管理 | 实操 |
| 第 4 课 | 矩形框标注实战（车辆检测） | 实操 |
| 第 5 课 | 图像分类标注实战（动物/场景分类） | 实操 |
| 第 6 课 | 多边形分割标注实战 | 实操 |
| 第 7 课 | 关键点标注实战（人体 17 点） | 实操 |
| 第 8 课 | 标注格式导出与转换（VOC / COCO / YOLO） | 实操 |
| 第 9 课 | CVAT 标注入门与任务管理 | 实操 |
| 第 10 课 | 综合练习：完成一个完整标注任务流程 | 实操考核 |

### 层级 2：规范与质量（12 课时）

**能力目标：** 能制定标注规范，评估和保证标注质量

| 课时 | 教学内容 | 教学方式 |
|------|---------|---------|
| 第 11 课 | 标注规范文档的编写方法与要素 | 讲座 + 案例分析 |
| 第 12 课 | 标签体系设计原则（互斥、完备、层次化） | 讲座 + 练习 |
| 第 13 课 | 质量指标详解：IOU / Precision / Recall / F1 / Kappa | 讲座 + 计算练习 |
| 第 14 课 | 质检流程设计（抽检比例、AQL、返工标准） | 讲座 + 模拟 |
| 第 15 课 | 标注员自检方法与技巧 | 讲座 + 实操 |
| 第 16 课 | 常见标注错误案例分析（漏标、多标、标签混淆） | 案例研讨 |
| 第 17 课 | 标注一致性评估（IAA）的计算与解读 | 讲座 + Python 编程 |
| 第 18 课 | 模拟质检：给定标注结果，找出所有错误 | 实战演练 |
| 第 19 课 | 错误分析与根因定位 | 案例研讨 |
| 第 20 课 | 根据质检结果修订标注规范 | 练习 |
| 第 21 课 | 标注平台 API 实现自动化质检脚本 | Python 编程 |
| 第 22 课 | 综合考核：制定一个标注规范 + 质检方案 | 大作业 |

### 层级 3：进阶标注（16 课时）

**能力目标：** 掌握多种复杂标注类型的操作和质量控制

| 课时 | 教学内容 | 教学方式 |
|------|---------|---------|
| 第 23 课 | 倾斜目标标注（旋转边界框 OBB） | 实操 |
| 第 24 课 | 密集场景标注技巧与遮挡处理 | 实操 |
| 第 25 课 | 文本分类标注实战（情感/意图/主题） | 实操 |
| 第 26 课 | 文本 NER（命名实体识别）标注实战 | 实操 |
| 第 27 课 | 关系抽取标注实战 | 实操 |
| 第 28 课 | 语音转写标注实战 | 实操 |
| 第 29 课 | 视频标注入门：关键帧标注与插值 | 实操 |
| 第 30 课 | 视频跟踪标注实战 | 实操 |
| 第 31 课 | 多人协作标注流程与冲突解决 | 模拟演练 |
| 第 32 课 | AI 辅助标注：使用 SAM / OWL-ViT 预标注 | 讲座 + 实操 |
| 第 33 课 | 预标注结果的审核与修正技巧 | 实操 |
| 第 34 课 | 标注数据的可视化与分析（Python + matplotlib） | 编程实战 |
| 第 35-38 课 | 综合项目：多模态标注任务的全流程实践 | 大项目 |

### 层级 4：项目管理（8 课时）

**能力目标：** 能够独立负责标注项目的规划、执行和交付

| 课时 | 教学内容 | 教学方式 |
|------|---------|---------|
| 第 39 课 | 标注项目启动流程 | 讲座 |
| 第 40 课 | 工作量估算与排期 | 讲座 + 练习 |
| 第 41 课 | 标注成本核算与报价 | 讲座 + 案例练习 |
| 第 42 课 | 标注团队组建与角色分工 | 讲座 + 模拟 |
| 第 43 课 | 标注进度管理与风险管控 | 案例研讨 |
| 第 44 课 | 数据安全与合规（法律法规 + 技术措施） | 讲座 + 案例分析 |
| 第 45 课 | 标注质量管理的统计学方法（AQL、SPC） | 讲座 |
| 第 46 课 | 结业项目：完成一个标注项目的全流程方案设计 | 大作业答辩 |

## 教学方式说明

- **理论课（占 40%）：** 讲座、案例讲解、视频教学
- **实操课（占 50%）：** 在标注平台上的动手操作、编程练习
- **考核/项目（占 10%）：** 阶段性考核和综合项目

## 考核评估体系

| 评估方式 | 占比 | 内容 |
|---------|------|------|
| 日常练习 | 20% | 每课后的标注练习 |
| 阶段性考核 | 30% | 每个层级结束后的标注质量测试 |
| 大作业 | 30% | 两个综合项目（规范制定 + 项目管理方案） |
| 期末考核 | 20% | 给定一批数据，限时完成标注 + 质检方案 |

## 教学资源需求

- 标注平台：Label Studio（自建服务器）+ CVAT
- 教学数据集：10+ 套不同场景的标注练习数据集
- 编程环境：Python + Jupyter Notebook
- 参考资料：《数据标注工程》、标注工具官方文档

## 参考

本教学计划参考 GB/T 41867-2022《信息技术 人工智能 数据标注通用要求》中关于标注人员能力要求的章节设计。
