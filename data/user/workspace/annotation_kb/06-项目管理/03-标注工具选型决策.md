## 按项目规模选型

### 微型项目（< 500 张图片）
- **推荐：** Label Studio（pip 安装即可，5 分钟上手下线）
- **备选：** Make Sense（Web 版，无需安装）
- **不建议：** CVAT（Docker 部署相对重）

### 小型项目（500-5000 张图片）
- **推荐：** Label Studio（个人或 2-3 人小团队）
- **备选：** CVAT（如果后续会扩展规模）
- **注意：** 单机标注即可，优先使用快捷键提升效率

### 中型项目（5000-50000 张图片）
- **推荐：** CVAT（任务分配 + 工作流管理 + 自动标注）
- **备选：** Label Studio Enterprise（团队协作管理）
- **关键需求：** 多人协作、任务分发、进度监控

### 大型项目（> 50000 张图片）
- **推荐：** CVAT（成熟的任务管理 + 自动标注管线）
- **补充：** 自建标注平台（定制化需求强时）
- **关键需求：** 自动预标注 → 人工修正 → 质检流水线

## 按标注类型选型

| 标注类型 | 首选工具 | 原因 |
|---------|---------|------|
| 图像分类 | Label Studio / Make Sense | 简单快速，无需复杂功能 |
| 目标检测（矩形框） | CVAT / Label Studio | 丰富的快捷键和批量操作 |
| 语义分割（多边形） | CVAT | 智能剪刀工具（Intelligent Scissors）提高效率 |
| 关键点标注 | CVAT / Label Studio | 支持骨骼模板 |
| 视频跟踪标注 | CVAT | 内置插值和跟踪功能，其他工具不适用 |
| 3D 点云标注 | CVAT | 唯一开源选择 |
| 文本分类/NER | Label Studio | 丰富的文本标注模板 |
| 语音转写 | Label Studio | 内置音频标注界面 |

## 教学中使用 Label Studio 的理由

1. **低门槛：** pip install 后一个命令即可启动，学生无需 Docker 或复杂配置
2. **友好的 UI：** 界面直观，新手 10 分钟可掌握基本操作
3. **丰富的模板：** 分类、检测、分割、NER、语音等封装好的模板，一键创建项目
4. **Python SDK / API：** 方便老师编写自动化评测脚本，批量检查学生标注结果
5. **开源免费：** 无商用限制

## 关键考察维度总结

在选择标注工具时，按以下优先级考虑：
1. **标注类型支持度**（最重要的硬性条件）
2. **导出格式兼容性**（是否支持下游模型训练框架）
3. **团队协作功能**（多人任务分配 + 进度监控）
4. **快捷键和效率工具**（影响标注速度 30%+）
5. **AI 辅助标注**（预标注 + 主动学习）
6. **社区活跃度**（决定遇到问题的解决速度）
