# 标注成本核算

标注成本核算是项目报价和预算管理的基础。准确的成本核算可以帮助项目经理做出合理的报价，也可以帮助客户理解"为什么标注这么贵"。

## 成本构成分析

| 成本项 | 占比 | 说明 |
|--------|------|------|
| 人力成本 | 70-80% | 标注员 + 质检员 + PM + 专家的工资和社保 |
| 工具/平台 | 5-10% | 开源工具免费（部署+运维人力另计），企业版按 License 收费 |
| 培训成本 | 3-5% | 新员工入职培训的教材、时间和考核成本 |
| 管理成本 | 8-10% | 项目管理的人力投入和时间成本 |
| 数据存储与传输 | 2-5% | 云服务器、带宽、存储费用 |
| 管理费/利润 | 10-20% | 公司的管理费用和合理利润 |

## 主流计价模型

### 模型 1：按框计价（Per Box）

**适用场景：** 目标检测（矩形框标注）

**价格参考：**
- 简单场景（单目标 < 3 框/图）：¥0.02 - ¥0.05 / 框
- 中等场景（3-10 框/图）：¥0.05 - ¥0.10 / 框
- 复杂场景（> 10 框/图）：¥0.10 - ¥0.30 / 框

**优点：** 按劳计酬，标注员有动力多标；成本与工作量线性相关
**缺点：** 标注员可能为追求数量而降低质量；对框大小的差异不敏感

### 模型 2：按图计价（Per Image）

**适用场景：** 图像分类、整体场景标注

**价格参考：**
- 简单分类（2-5 类，单选）：¥0.10 - ¥0.50 / 图
- 复杂分类（10+ 类，多选）：¥0.50 - ¥2.00 / 图
- 精细分割（多边形逐目标标注）：¥2.00 - ¥10.00 / 图

**优点：** 简单明了，适合分类任务
**缺点：** 图片难度差异大时难以统一定价——建议分难度等级定价

### 模型 3：按工时计价（Per Hour）

**适用场景：** 复杂标注（3D 点云、医学影像分割）、研究型标注（规则不断调整）

**价格参考：** ¥30 - ¥80 / 小时（根据地域、标注难度和标注员经验浮动）

**优点：** 适应性强，适合规则不确定的项目
**缺点：** 对标注员效率没有激励，需要监督工时利用率

### 模型 4：按月薪（Full-time）

**适用场景：** 长期项目（> 3 个月）、专职标注团队

**价格参考：** ¥4000 - ¥12000 / 月（初级 - 高级标注员）

**优点：** 团队稳定，质量和效率有保障
**缺点：** 固定成本高，不适合短期项目

## 降本增效策略

### 策略 1：使用预标注模型

利用大模型（如 SAM、OWL-ViT）进行自动预标注，人工从"从零画框"变成"审核修正"。

**预期降本效果：** 减少 30%-50% 人工标注时间
**适用场景：** 目标检测、语义分割（常见类别）
**注意：** 预标注模型的结果仍需要人工修正，不可完全无人审核

### 策略 2：优化标注工具和流程

- 配置快捷键模板（一键选标签 + 一键画框）
- 使用批量操作（同类标签批量标注）
- 关闭不必要的 UI 动画减少操作延迟
- 标注工具的自动保存功能（避免崩溃数据丢失）

**预期提效：** 20% - 30%

### 策略 3：自动化质检

- 批量脚本检查格式错误（JSON 语法、必填字段）
- 坐标范围合理性检查（框的坐标不能超出图片尺寸）
- 类别数量统计（检测是否有标注员只标了 1-2 种类别）
- 框面积异常检测（框的尺寸是否与标签类型合理匹配）

**预期效果：** 减少质检员 30%-40% 的格式检查时间

### 策略 4：分级定价

- 简单任务分配给新手标注员（成本低）
- 复杂任务分配给资深标注员（效率高）
- 质检任务分配给经验最丰富的标注员（降低返工率）

## 报价计算示例

**项目：** 20,000 张街景图片，每张预计 8 个矩形框，中等复杂度，质检标准 IOU ≥ 0.85

```
框数总量 = 20000 × 8 = 160,000 框
按框计价 = 160,000 × ¥0.08 = ¥12,800
加管理费 15% = ¥12,800 × 1.15 = ¥14,720
总计报价 = ¥15,000（含税）
```
