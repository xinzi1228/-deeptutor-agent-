# 标注进度管理

标注进度管理的核心目标是保证项目按时按质交付，避免因进度失控导致的违约风险。

## 进度管理三板斧

**计划 → 跟踪 → 调整** 的闭环管理，缺一不可。

## 第一步：制定合理计划

### 倒推法制定里程碑

1. **确定截止日期 D：** 根据合同或需求方要求确定最终交付日期
2. **预留缓冲期：** D - 15% 的时间作为内部截止日期（应对突发风险）
3. **拆分里程碑：**
   - M1：需求确定 + 规范完成（D-90%）
   - M2：试标注完成 + 规范修订（D-80%）
   - M3：培训考核完成（D-75%）
   - M4：25% 数据量完成（D-55%）
   - M5：50% 数据量完成（D-35%）
   - M6：75% 数据量完成（D-18%）
   - M7：100% 数据量完成 + 全量质检（D-10%）
   - M8：格式转换 + 交付包准备（D-3%）

### 日标注量目标计算

```
每日标注量目标 = 剩余数据量 / 剩余工作日
剩余工作日 = 内部截止日期天数 × 调整系数
```

- 标注初期（前 3 天）：实际产能 × 0.7（学习曲线上升期）
- 稳定期（第 4 天起）：实际产能 × 1.0
- 收尾期（最后 3 天）：实际产能 × 1.1（标注员熟练度最高）

## 第二步：进度跟踪

### 跟踪工具与指标

| 指标 | 用途 | 预警阈值 |
|------|------|---------|
| 日完成量 | 是否达到日目标 | < 目标的 85% 连续 2 天 |
| 累计完成率 | 整体进度 | 落后计划 > 5% |
| 质检一次通过率 | 质量趋势 | < 90% 连续 2 天 |
| 返工积压量 | 返工是否成为瓶颈 | > 当日标注量的 20% |
| 标注员出勤率 | 人手充足性 | 减员 > 20% |

```

```

### 燃尽图（Burndown Chart）

X 轴 = 日期，Y 轴 = 剩余工作量。理想的燃尽曲线应紧贴"理想任务线"（从起始日期到截止日期的一条平滑斜线）。如果实际曲线持续高于理想线 → 进度滞后；如果持续低于理想线 → 可能质量把关不严。

## 第三步：异常预警与调整

### 进度风险预警信号与应对

| 预警信号 | 可能原因 | 应对措施 |
|---------|---------|---------|
| 连续 2 天未达日标 | 标注难度超出预期 / 工具效率低 / 标注员疲劳 | 分析瓶颈 → 优化快捷键 / 简化规范 / 增加休息 |
| 质检退回率突增 | 标注员赶进度牺牲质量 / 新场景规范未覆盖 | 暂停标注 → 分析错误原因 → 培训 → 恢复标注 |
| 关键标注员请假 | 生病 / 突发事件 | 启用后备人员、适当延长截止日期 |
| 燃尽曲线持续上翘 | 返工积压 / 数据难度不均 | 重新估算剩余工时、向客户沟通调整截止日期 |
| 质检员成为瓶颈 | 质检效率 < 标注产出 | 增加质检员、降低部分已稳定数据的抽检比例 |

### 催进度的误区

- ❌ **单纯要求加速：** "大家加快速度！"——标注员会在质量上偷工减料
- ❌ **延长工作时间：** 加班标注 → 疲劳 → 错误率上升 → 返工增加 → 实质进度更慢
- ✅ **分析瓶颈 → 优化工具/流程/规范 → 在保证质量的前提下提效**

## 进度管理黄金法则

> **"标注质量是第一位的。宁可延期交付高质量数据，也不要按时交付一堆噪声。"**

模型训练的 Garbage In, Garbage Out 原则决定了低质量标注数据的危害远大于延期交付。
