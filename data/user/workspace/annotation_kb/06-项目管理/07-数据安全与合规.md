# 标注数据安全与合规

标注数据往往包含大量敏感信息——人脸、车牌、身份证号、医疗影像、商业机密——一旦泄露，不仅造成经济损失，还可能违反法律法规。数据安全不是标注项目的"附加项"，而是刚性底线。

## 数据分级与保护措施

| 数据级别 | 典型示例 | 必选安全措施 | 建议安全措施 |
|---------|---------|------------|------------|
| **L1 公开数据** | 公开数据集、科研发布数据 | 无特殊要求 | 来源追溯 |
| **L2 内部数据** | 公司内部业务图片、脱敏后的用户数据 | 权限控制、VPN 访问、禁止外传、加水印 | 水印含标注员 ID、操作日志 |
| **L3 敏感数据** | 含人脸/车牌的街景、含姓名的文本、含位置的 GPS 数据 | L2 全部 + 数据脱敏 + 专用标注环境 + 禁用截屏 | 物理安全区域、终端管控 |
| **L4 机密数据** | 医疗影像、军事侦察图像、金融交易记录 | L3 全部 + 物理隔离环境 + 无互联网连接 + 进出安检 | 专人陪同、双人操作审批 |

## 安全措施清单

### 1. 访问控制（Access Control）

- 每个标注员使用唯一的个人账号，禁止共享账号
- 遵循最小权限原则：标注员只能访问自己负责的数据子集
- 定期（每月）审查账号权限，离职员工当天注销账号
- 密码策略：长度 ≥ 12 位，含大小写字母 + 数字 + 特殊字符

### 2. 环境隔离（Environment Isolation）

- L4 级数据：标注环境与互联网物理隔离（独立机房 + 封闭网络）
- L3 级数据：标注环境与办公网络隔离（独立 VLAN）
- 禁止在标注工作站上安装 QQ、微信、网盘等具备文件外传功能的软件
- 标注工作站不接入任何无线网络

### 3. 数据脱敏（Data Masking）

- 在数据进入标注环境之前完成脱敏处理
- 人脸区域自动模糊或替换（使用 OpenCV 或专业脱敏 SDK）
- 车牌号自动识别 + 打码覆盖
- 身份证号 / 手机号正则匹配 + 替换为占位符
- 脱敏后的数据不可逆

### 4. 操作审计（Audit Log）

记录所有关键操作：
- 数据的上传、下载、导出、删除时间 + 操作人 + IP 地址
- 标注结果的修改记录（谁在什么时间修改了什么）
- 异常操作告警：批量导出、非工作时间大量下载、多次登录失败

### 5. 终端管控（Endpoint Security）

- 禁用 USB 接口（物理封堵或组策略禁用）
- 禁止截屏和录屏（通过标注平台的防截屏功能 + 终端软件管控）
- 禁止安装非授权软件（通过白名单策略）
- 操作系统和杀毒软件保持最新安全补丁

### 6. 保密协议（NDA）

所有标注员在入职时必须签署保密协议（Non-Disclosure Agreement），明确：
- 保密信息的范围（标注数据、标注规范、甲方信息）
- 保密期限（通常在合同结束后仍需保密 2-5 年）
- 违约后果（承担法律责任 + 经济赔偿）

## 交付后数据销毁

标注项目交付后，本地存储的数据必须按合同约定时间销毁：
- **不是简单删除！** 普通删除操作只在文件系统中标记为"已删除"，数据仍可恢复
- **安全擦除标准：** 使用专业工具（如 srm、shred、File Shredder）覆写磁盘 3-7 次
- **SSD 注意事项：** SSD 的磨损均衡机制可能导致数据无法被安全擦除——机密级数据建议使用 HDD 存储
- 数据销毁后出具《数据销毁确认书》并双方签字留存

## 法律与合规

**中国法规依据：**
- 《网络安全法》：要求网络运营者对用户数据进行安全保护
- 《数据安全法》：建立数据分类分级保护制度
- 《个人信息保护法》：处理个人信息需取得同意，人脸等敏感信息需单独同意
- GB/T 35273-2020《个人信息安全规范》：对个人信息脱敏、存储、传输的具体技术规范
- GB/T 41867-2022《信息技术 人工智能 数据标注通用要求》：数据标注行业的国家标准

**标注项目的合规要求：**
1. 若数据含个人信息 → 需有用户授权协议或数据来源于公开数据集且已合法授权
2. 不得标注违法内容（如暴力、色情、违反公序良俗的内容）
3. 标注员有权拒绝标注令其不适的内容（需提前建立内容安全审核机制）

## 培训要点

标注团队入职安全培训的必讲内容：
1. 公司数据安全政策和奖惩制度
2. 各类安全事件的报告流程
3. 社会工程学攻击的识别（钓鱼邮件、冒充电话等）
4. 真实数据泄露案例分析
