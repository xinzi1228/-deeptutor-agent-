# 标注项目启动流程（SOP）

标注项目启动是决定项目成败的关键阶段。规范的启动流程可以有效避免中后期的需求变更、大规模返工和团队混乱。

## 阶段一：需求沟通（1-3 天）

在项目正式启动前，项目经理需要与需求方（甲方或算法团队）完成以下沟通：

1. **明确标注目的：** 数据用于模型训练、模型评测、学术研究还是产品演示？不同目的对标注精度的要求差异巨大
2. **确定标注类型：** 目标检测 / 语义分割 / 图像分类 / 关键点检测 / 文本 NER / 视频跟踪 → 决定工具选型和人员配置
3. **确认交付物：** 标注格式（COCO / VOC / YOLO / 自定义 JSON）、文件命名规则、标注属性字段
4. **评估数据规模：** 图片数量 / 视频总时长 / 文本条数、预计每样本标注目标数量
5. **明确验收标准：** IOU 阈值、准确率、召回率、Kappa 系数的最低要求

**输出产物：** 《标注需求文档》（Annotation Requirement Document / ARD）

## 阶段二：规范制定（2-5 天）

标注规范是整个项目的"法律文件"，所有标注员的行为准则。

1. **编写标注规范文档：**
   - 标签体系定义（每个标签的名称、含义、适用/不适用场景、图文正反例）
   - 标注规则（框的绘制方式、遮挡处理原则、边界判定标准）
   - 属性填写规范（哪些场景需要填写哪些属性、可选值列表）
   - 特殊场景处理规则（夜间、雨雪天、遮挡、截断、模糊）

2. **设计标签体系：** 层次化 + 互斥性 + 完备性 → 每个目标恰好属于一个标签，不存在"不知道选哪个"的兜底标签

3. **制作金标准样本：** 由标注专家标注 10-20 张图，作为培训教材和后续质量基准

4. **设计质检标准和采样策略：** 抽检比例、AQL 标准、返工阈值

**输出产物：** 《标注规范手册》+ 金标准样本集

## 阶段三：试标注（2-3 天）

试标注是发现问题的最低成本阶段。

1. 选择 3-5 名标注员试标 50-100 张样本
2. 计算标注员间一致性（IAA / Kappa）：Kappa ≥ 0.7 合格，< 0.6 需要修改规范
3. 收集试标注中的反馈：规范中哪些描述不清晰？哪些规则难以执行？哪些场景没有覆盖到？
4. 根据试标结果修订标注规范

**输出产物：** 《试标注分析报告》+ 修订后的标注规范 v2.0

## 阶段四：正式标注启动

1. **全体标注员培训：** 讲解标注规范 + 金标准演示 + 陷阱案例练习 + 考核测试
2. **考核通过标准：** 标注员在考核集上的 Kappa ≥ 0.8 方可进入正式标注
3. **投入正式标注：** 质检 + 反馈循环正式运行
4. **周例会机制：** 每周复盘标注质量数据，持续优化流程

## 关键检查点（Checkpoint）

| 阶段 | 门禁条件 | 未达标处理 |
|------|---------|-----------|
| 需求 → 规范 | ARD 经双方签字确认 | 补充需求细节 |
| 规范 → 试标 | 规范文档含完整正反例 | 补充示例 |
| 试标 → 正式 | Kappa ≥ 0.7 | 重新培训 / 修订规范 |
| 正式标注 | 日质检通过率 ≥ 95% | 暂停标注、分析原因 |
