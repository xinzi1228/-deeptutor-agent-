# 分类标注常见错误

图像分类标注看似最简单——只需要从几个标签中选一个，但实际生产中出现的错误类型并不少。以下是最常见的四大陷阱。

## 错误 1：多目标图片处理不当

**场景：** 一张图片中同时出现了猫、狗、鸟三种动物。

**错误做法：** 标注员在"猫"、"狗"、"鸟"三个标签之间犹豫不决，最终随便点击了一个标签提交。

**问题：** 这样标注出来的数据集存在信息丢失——模型不知道这张图里还有另外两种动物，训练时会产生混乱的信号。

**正确做法：**
- 如果任务是"单标签分类"，规范应事先约定处理策略——选择画面占比最大的目标作为主标签，或设置 `mixed`（混合场景）标签
- 如果任务是"多标签分类"，标注时可以勾选多个标签（猫 + 狗 + 鸟）
- **核心原则：** 标注规范和标签体系必须在标注开始之前解决多目标问题

## 错误 2：主观判断标准不一致

**场景：** 图片标注任务中有"画质好 / 画质差"的主观分类。

**问题：** 不同标注员的审美标准差异巨大——有人觉得"有颗粒感是种风格"，有人觉得"有颗粒感就是画质差"。

**解决：**
- 避免主观标签——将"画质好/差"改为可量化的客观指标："分辨率 ≥ 1920×1080 & 无明显噪点 → 高清；否则 → 标清"
- 如果必须使用主观标签，提供评定量表——如 1-5 分的示例对照图
- 建立"金标准"样本库，标注员在标注前必须通过金标准测试

## 错误 3：忽略图片整体上下文

**场景：** 标注员只关注图片的局部区域就做出了分类判断。

**案例：** 一张餐厅内景的图片，标注员看到了桌上的食物特写就分类为"美食"，但图片的整体场景是"室内用餐环境"。在细粒度场景分类任务中，这类错误很常见。

**解决：** 标注流程中加入"全局浏览→局部细节→最终判定"三步法。先花 3 秒看整张图的全貌，再检查关键细节，最后做分类决定。

## 错误 4：细粒度分类不准

**场景：** 标注任务是区分 120 种犬种。

**常见问题：**
- 哈士奇 vs 阿拉斯加雪橇犬——外观极其相似但属不同犬种
- 拉布拉多 vs 金毛寻回犬——幼犬阶段几乎无法分辨
- 边境牧羊犬 vs 澳大利亚牧羊犬——花色相近但体型不同

**解决策略：**
1. 为每个犬种准备"关键区分特征清单"（毛色模式、耳朵形状、尾巴姿态、体型比例）
2. 标注工具中嵌入犬种图鉴，标注员可随时点击查看参照图
3. 对无法确定的样本，设置 `uncertain=true` 标记并提交给专家审核
4. 标注任务按犬种相似度分组——将容易混淆的犬种放在同一批标注任务中，让标注员在对比中做选择

## 错误 5：标签编号惯性点击

**场景：** 连续标注 200 张图片，编号 1-3 是正例（需要选的标签），编号 4-8 是其他标签。标注员在大量重复后，形成了"总是点编号 2"的肌肉记忆，遇到编号 4 才是正确答案的图片时也习惯性点了编号 2。

**解决：**
- 标注工具随机排列标签选项的位置（打乱编号）
- 在每 N 张标注后插入"注意力检查题"（故意放一张明显属于其他标签的图片）
- 标注员自检时关注"标签点击位置是否可疑"

## 教学建议

分类标注教学中应强调"标注规范比专业知识更重要"——只要规范定义得足够清晰，非专业人士也能达到专家的标注一致性。让学员体会"模糊定义 → 标注混乱"和"精确规则 → 标注统一"的对比差异。
