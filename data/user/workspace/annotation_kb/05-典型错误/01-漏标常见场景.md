# 漏标常见场景分析

漏标（漏检）是目标检测标注中最高频的错误，约占所有错误的 40%。

## 高频漏标场景

### 1. 小目标漏标

远处的行人、路边的交通标志、角落里的物体，这些目标尺寸小（通常 < 32×32 像素），标注员容易在快速浏览时直接跳过。

**原因：** 目标尺寸过小，视觉显著性低，尤其在缩略图模式下几乎不可见。

**解决：**
- 放大图片检查（建议 ≥ 200% 缩放比例）
- 先从大目标开始标注，再逐级查找小目标
- 养成扫描四角、边缘区域的习惯
- 使用标注工具的高亮/对比度功能辅助检测

### 2. 遮挡目标漏标

被树木、建筑物、其他车辆遮挡的物体，或密集人群中被遮挡的个体，因目标不完整，视觉上容易被忽略。

**解决：**
- 有规则地逐区域扫描，而非随机浏览
- 遮挡严重（> 70%）的目标可不标注，但需在属性中标记 `occlusion_level=severe`
- 标注规范中明确遮挡可标/不可标的判定标准

### 3. 边缘目标漏标

图片边缘被截断的目标容易被忽略，因为标注员的注意力通常集中在图片中央区域。

**解决：**
- 标注时从图片边缘开始，向中心推进
- 边缘目标可见部分 ≥ 50% 时仍需标注
- 训练时有意识地先扫视四边四角

### 4. 与背景颜色相近的目标

黑色车辆在阴影中、绿色物体在草地上、白色衣物在白墙前——目标与背景的视觉对比度极低。

**解决：**
- 调整图片亮度、对比度、饱和度辅助查看
- 使用标注工具的颜色空间切换功能（如灰度模式）
- 在复杂背景场景下降低标注速度，增加自检频率

### 5. 密集场景中的个体漏标

拥挤的街道、鸟瞰停车场、超市货架等密集场景中，相邻目标相互重叠，标注员容易漏掉中间的个体。

**解决：**
- 从左上到右下的网格扫描法，不跳行
- 标注完一个区域后用计数器核对目标数量

## 教学建议

让学员标注完后将原图旋转 180° 再复查一次——打乱视觉惯性后，大脑会重新识别之前忽略的区域，更容易发现漏标。这是一个经过验证的低成本高效质检方法。
