# 边界模糊处理错误

边界模糊是指目标与背景之间或相邻目标之间没有清晰的视觉边界，常见于分割标注和关键点标注任务。在高精度场景下，边界模糊是导致 IOU 无法达标的头号障碍。

## 典型场景与处理原则

### 1. 毛发 / 羽毛边缘

**场景：** 标注猫、狗等动物的多边形轮廓时，边缘布满毛发细丝。

**常见错误：** 标注员沿着每一根毛发的边缘精细描点，结果轮廓呈锯齿状，每个描点的偏差在 ±5 像素左右，多边形整体显得极不自然。

**正确做法：**
- 沿着毛发的大致外轮廓（±3 像素容差），保持轮廓平滑
- 细小的毛发末端可忽略，以"主体轮廓"为准
- 标注规范中应明确规定毛发的容错范围和描点密度

### 2. 半透明物体

**场景：** 标注玻璃橱窗、水面倒影、半透明塑料瓶等物体。

**典型错误：** 将玻璃后的物体也圈入玻璃的标注范围内；或将水面倒影中的物体当作独立对象标注。

**处理原则：**
- 半透明物体后的物体不标注（或单独标记为 `behind_transparent=true`）
- 水面中的倒影不是真实物体，不标注。标注规范中应明确说明"镜面和倒影不纳入标注范围"
- 如果半透明物体本身就是标注目标（如玻璃瓶），按可视轮廓标注即可

### 3. 夜景 / 暗光场景

**场景：** 夜间道路监控或手机夜景模式拍摄的图片，车辆和行人的边缘与暗色背景融为一体。

**处理原则：**
- 以车灯轮廓 + 车身反光 + 上下文推断边界
- 在属性中标记 `lighting=low_light` 或 `illumination=poor` 供模型训练时区别对待
- 不必要求暗光场景下的标注精度达到白天同等水平——标注规范中为不同光照条件设定不同的精度标准

### 4. 运动模糊

**场景：** 快速移动的车辆或奔跑的行人产生运动拖影，物体边缘呈半透明的"彗星尾"状模糊。

**常见处理方式争议：**
- 方案 A：只框出物体清晰部分（忽略拖影区域）
- 方案 B：框的范围覆盖整个拖影区域

**推荐方案：** 采用方案 B。因为模型在推理时面对的运动模糊对象也将呈现拖影形态，训练样本应覆盖拖影区域，让模型学习到运动模糊特征的分布规律。同时标记 `motion_blur=true` 属性。

### 5. 烟雾 / 雾气中的目标

**场景：** 雾天场景中的远距离车辆，轮廓被雾气模糊。

**处理原则：**
- 如果目标类别可明确判断且大致位置可确定 → 标注
- 如果完全无法判断类别 → 不标注
- 标记 `weather=fog/haze` 和可见度等级

### 6. 密集重叠目标边界

**场景：** 密集人群或堆积货物场景中，多个目标的轮廓交错重叠。

**最佳实践：**
- 标注时按从近到远、从清晰到模糊的顺序
- 先标最"完整"的目标，其边界可覆盖被其遮挡的目标的部分区域
- 使用 `z_order` 属性记录目标的层级关系

## 教学建议

设计"边界判断"专项练习：选择一批边界模糊的图片（毛发、暗光、运动模糊各几张），先让学员自主标注，然后对比专家标注结果，分析偏差来源和边界判断逻辑。这是提升标注员精细化标注能力的关键训练环节。
