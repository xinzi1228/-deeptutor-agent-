# 多标错误（误检）分析

多标（False Positive / 误检）指标注了不应标注的内容，是仅次于漏标的第二高发错误类型。

## 常见多标场景

### 1. 背景误认为目标

这是最经典的多标错误——将非目标对象当作目标标注。

**典型案例：**
- 路边广告牌上的汽车图案被当作真实汽车标注
- 水洼中的倒影被当作真实物体标注
- 墙上的海报/壁画中的人物被当作真实人物标注
- 玩具车/模型被当作真实车辆标注

**解决：** 标注规范中必须明确——只标注真实存在的物体，不标注镜像、倒影、图案、照片中的二次影像、模型玩具等"类目标"物。

### 2. 不可标注类别误标

标注员对标签定义理解不准确，将不在标注范围内的对象标为目标。

**典型案例：**
- 标注"机动车"时，将滑板车、婴儿车、轮椅也标注为 vehicle
- 标注"行人"时，将雕像、假人模特也标注为 person
- 标注"动物"时，将卡通玩偶、雕塑动物也纳入

**解决：** 精确化标签定义，提供不可标注类别的排除清单。每个标签应附带"正面示例"和"负面示例"两张参照图。

### 3. 区域误判 / 碎片化标注

同一个物体因视觉特征不连续而被拆分为多个标注框。

**典型案例：**
- 穿着条纹衣服的行人被分成上下两部分各标一个框
- 卡车因中间被电线杆遮挡，标注员对左右两侧各标一个框
- 不连续的颜色块被误判为多个独立目标

**解决：** 明确标注原则——同一物体只标一个框，因遮挡或颜色造成的视觉断裂应通过上下文判断是否属于同一目标，碎片需要合并且标注遮挡属性。

### 4. 标注范围膨胀

框的范围过大，包含了大量背景区域，虽然目标被"框住"了，但框内的背景比例过高。

**案例：** 对一辆汽车标注时频繁包含上方天空和侧方路面，导致有效目标占比 < 60%。

**解决：** 强调"最小外接矩形"原则，框的四边应紧贴目标的真实外轮廓边界。

## 预防措施

1. 标注规范中设置明确的正例/反例对照表，图文并茂
2. 新手培训中增加"陷阱案例"练习（故意掺杂容易误标的图片）
3. 标注工具中标签名旁配样本缩略图，减少记忆错误
4. 试标注阶段统计高频误标类型，针对性修改规范
