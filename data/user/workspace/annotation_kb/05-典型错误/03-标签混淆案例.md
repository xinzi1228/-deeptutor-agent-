# 标签混淆案例分析

标签混淆是初学者最常见的错误之一，约占标注错误的 30%。其本质是标注员对标签定义的理解边界模糊，导致本应标 A 标签的目标被标成了 B 标签。

## 高频混淆对

### 1. 相似外观混淆

| 容易混淆对 | 区分要点 |
|-----------|---------|
| 出租车 vs 私家车 | 出租车通常有车顶灯牌 + 统一颜色涂装（黄/绿） |
| 公交车 vs 长途大巴 | 看车身标识：公交车有路线号牌、投币箱；大巴有行李舱 |
| 自行车 vs 电动自行车 | 看是否有电池仓（脚蹬下方或坐垫下的电池包）和排气管 |
| 猫 vs 小型犬 | 耳朵形状（猫耳尖三角、犬耳圆/垂）、尾巴姿态 |
| 指示灯红 vs 橙 | 颜色在图片中可能偏色——看上下文：刹车灯/转向灯 |

### 2. 层级关系混淆

当标签体系存在父子关系时，容易出现跨层级标注。

**案例 1：SUV 单列问题**
- 标注员 A 将 SUV 标为 `car`（父类），标注员 B 将 SUV 标为 `suv`（子类）
- 问题根源：标签体系同时存在父子类
- 解决方案：SUV 统一使用父类 `car`，或者使用层级标签结构 `car.suv`

**案例 2：军用车辆归类问题**
- 坦克、装甲车应该标为 `military_vehicle` 还是 `vehicle`？
- 取决于标注任务的需求：如果是城市交通场景检测，军用车辆极少出现，可统一标为 `vehicle`；如果是安防场景，需要单独区分

### 3. 上下文依赖型混淆

同一外观的物体在不同场景下可能属于不同标签。

**案例：停靠状态的行人判断**
- 场景：路边坐着的人、靠墙站着看手机的人
- 问题：是否应标为"行人（pedestrian）"？
- 判决标准：看姿态与场景——坐在长椅上的不是行人，站在人行道/马路中的才是行人。姿态 + 位置共同判断。

**案例：交通标志 vs 商业广告牌**
- 长方形带文字→注意区分：有路名/编号的是交通标志，有电话/价格的是广告牌

### 4. 细粒度分类混淆

**案例：哈士奇 vs 阿拉斯加雪橇犬**
- 哈士奇：三角形立耳、尾巴下垂不卷、体型较修长
- 阿拉斯加：耳距较宽、尾巴向背上卷曲、体型更壮实

**案例：轿车 vs 掀背车 vs 旅行车**
- 看 C 柱之后的造型：三厢轿车有独立的尾部行李箱、掀背车尾部与座舱连通、旅行车车顶一直延伸到尾部

## 教学建议

对每对易混淆标签制作对比卡片——正反面各放一张正例图片，标注关键区分特征。学员标注时随时翻看参考。试标注阶段故意投放混淆案例测试学员的辨析能力。
