# 标注类型概览

数据标注按数据模态和标注目的分为多种类型，不同类型对标注员的技能要求和工具支持各不相同。本章建立标注类型的完整知识框架。

## 一、图像标注

图像标注是应用最广泛、需求量最大的标注类型。

### 1.1 目标检测（Bounding Box / Object Detection）
用矩形边界框标出图像中每个目标物体的位置和类别。这是最基础的图像标注形式，广泛应用于自动驾驶、安防监控、零售货架识别等场景。

### 1.2 语义分割（Semantic Segmentation）
对图像中的每个像素赋予类别标签，不需要区分同类中的不同个体。例如：将所有道路区域标注为同一类，所有行人标注为同一类。常用于自动驾驶的可行驶区域分析和医学影像的病灶分割。

### 1.3 实例分割（Instance Segmentation）
在语义分割的基础上，进一步区分同类中的不同个体。例如：不仅要标注出"人"的区域，还要区分出"张三"和"李四"是不同的实例。COCO 数据集同时包含目标检测框和实例分割标注。

### 1.4 关键点标注（Keypoint Annotation）
标注目标物体上的特定关键点位，如人体姿态估计中的 17 个骨骼关键点（肩、肘、腕、髋、膝、踝等），人脸识别中的 68 个面部特征点，手势识别中的 21 个手指关节点。

### 1.5 图像分类（Image Classification）
对整张图片赋予一个或多个类别标签，不关心目标在图片中的位置。例如：判断一张图片是"猫"还是"狗"，判断一张医学影像是否有"肿瘤"。

### 1.6 目标跟踪（Object Tracking）
在视频帧序列中持续追踪同一目标，通常结合检测框和唯一 ID。用于监控视频中的行人跟踪、自动驾驶中的多目标跟踪（MOT）。

## 二、文本标注

### 2.1 命名实体识别（NER）
识别文本中的人名、地名、机构名、时间、日期、货币金额等实体，并标注其类别和位置（起始和结束位置）。

### 2.2 关系抽取（Relation Extraction）
标注文本中实体之间的关系类型，如"张三"与"北京大学"的关系为"校友"。

### 2.3 情感分析（Sentiment Analysis）
判断文本的情感极性：正面、负面、中性，以及更细粒度的情绪分类（愤怒、悲伤、喜悦、惊讶等）。

### 2.4 文本分类与意图识别
对文本进行主题分类或识别用户意图（如"订机票"、"查天气"、"投诉"等）。

## 三、音频标注

包括语音转写（ASR）、说话人分离（Speaker Diarization）、语音情感标注、音频事件检测（枪声、玻璃破碎声等）。

## 四、视频标注

包括行为识别（跑步、打架、摔倒）、时序动作定位（找到动作的起止时间）、多目标跟踪等。

## 五、3D 点云标注

主要用于自动驾驶和机器人领域，对激光雷达采集的 3D 点云数据进行目标检测框标注（3D Bounding Box）和语义分割。
