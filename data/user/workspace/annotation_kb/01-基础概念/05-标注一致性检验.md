# 标注一致性检验

## 定义

标注一致性（Annotation Consistency / Inter-annotator Agreement）是指不同标注人员对同一批数据独立标注后，标注结果之间的一致程度。它是衡量标注规范是否清晰、标注员是否理解到位的重要指标。

如果不同标注员对同一张图的标注结果差异很大，说明标注规范不够清晰或培训不到位，需要及时改进。

## 常用检验指标

### 1. Cohen's Kappa 系数

用于衡量两位标注者之间的一致性，可用于分类标注任务（如图像分类、文本情感分类）。

**公式：**
```
κ = (P_o - P_e) / (1 - P_e)
```
其中 P_o 是两位标注者实际观察到的一致比例，P_e 是随机一致的概率期望值。

**Kappa 值的判定标准：**

| κ 范围 | 一致性程度 |
|---------|-----------|
| κ ≥ 0.81 | 几乎完全一致（Almost Perfect） |
| 0.61 ≤ κ < 0.80 | 基本一致（Substantial） |
| 0.41 ≤ κ < 0.60 | 中等一致（Moderate） |
| 0.21 ≤ κ < 0.40 | 一般一致（Fair） |
| κ < 0.21 | 轻微一致（Slight） |

标注项目中通常要求 κ ≥ 0.60，高质量项目要求 κ ≥ 0.80。

### 2. Fleiss' Kappa 系数

Cohen's Kappa 的扩展，用于衡量三位及以上标注者之间的一致性，适用于有多个标注员同时对同一批数据进行标注的场景。

### 3. 目标检测中的一致性度量

对于目标检测任务，一致性不仅看类别判断，还要看位置标注的重合度：

- **IOU 阈值匹配**：两个标注员标注的框，IOU ≥ 0.5 且类别一致则视为"一致标注"
- 统计一致标注的比例作为一致性得分

## 一致性检验流程

### 步骤一：一致性样本抽取

从待标注数据中随机抽取 10%-20% 的样本作为一致性检验样本（通常 50-200 张图片）。所有参与项目的标注员独立对这些样本进行标注。

### 步骤二：计算一致性指标

将标注结果汇总，按标注类型选用合适的指标（Kappa、IOU 匹配率等）计算一致性得分。

### 步骤三：结果分析

- **κ ≥ 0.80**：一致性良好，规范清晰，可进入正式标注阶段
- **0.60 ≤ κ < 0.80**：一致性基本达标，需对有争议的标注项进行讨论并细化规范
- **κ < 0.60**：一致性不足，必须重新培训或修改标注规范后再次进行一致性检验

### 步骤四：定期复检

在正式标注过程中，建议每周进行一次一致性检验（3-5 人参与），防止"标注标准漂移"（随时间的推移，标注员的标注标准逐渐偏离最初规范）。

## 教学要点

1. **强调一致性 ≠ 同一个人多次标注结果一致**——必须是**不同**标注员之间的独立标注一致
2. **"标注标准漂移"概念**：标注员随着时间推移可能无意间偏离规范，需要通过定期一致性检验及时发现和纠正
3. **实战练习**：让学员分两组独立标注同一批样本，计算一致性得分并讨论差异原因
