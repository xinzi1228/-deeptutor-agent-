# 精确率（Precision）与召回率（Recall）

精确率和召回率是评估标注和模型性能的两个基本但至关重要的指标，二者从不同维度衡量标注质量。

## 基本概念

为了理解精确率和召回率，首先需要掌握混淆矩阵中的四个基本计数：

| 术语 | 英文 | 含义 |
|------|------|------|
| TP | True Positive | 预测框与真值框匹配成功（标注正确） |
| FP | False Positive | 多标的框——不应标注的东西被错误标注 |
| FN | False Negative | 漏标的框——应该被标注的目标却没有标 |
| TN | True Negative | 正确未标注（背景区域未被误标） |

## 精确率（Precision）

**定义：** 在所有被预测为正例（标注为目标）的框中，真正正确的比例。

**公式：**
```
Precision = TP / (TP + FP)
```

**含义：** 查准率——标注出的框中，有多少是正确的？

**通俗类比：** 警察抓了 10 个人，其中 8 个是真小偷，2 个是误抓的无辜者。Precision = 8/10 = 80%。

**高 Precision 低 Recall 的场景：** 标注员非常谨慎，只标自己确信的目标，导致漏标很多。标注结果"宁缺毋滥"。

## 召回率（Recall）

**定义：** 在所有应该被标注出的目标中，实际被正确标注的比例。

**公式：**
```
Recall = TP / (TP + FN)
```

**含义：** 查全率——所有应该被标出的目标中，实际标出了多少？

**通俗类比：** 在场共有 10 个真小偷，警察抓到了 8 个，漏了 2 个。Recall = 8/10 = 80%。

**低 Precision 高 Recall 的场景：** 标注员把所有可疑目标都标上了，宁可错标也不漏标，导致误标很多。

## F1 分数

F1 分数是精确率和召回率的调和平均数，能够综合反映标注质量。

**公式：**
```
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

**特性：**
- F1 ∈ [0, 1]，越接近 1 质量越高
- 只有当 Precision 和 Recall 都高时，F1 才会高
- 如果 Precision 或 Recall 任一为 0，则 F1 = 0

## Precision-Recall 权衡

在实际标注工作中，Precision 和 Recall 往往存在此消彼长的关系：

- **提高 Precision 的方法：** 提高标注阈值（如提高 IOU 要求），减少 FP
- **提高 Recall 的方法：** 降低标注阈值，尽可能覆盖所有目标，减少 FN

质量管理的目标是使两者同时达到可接受的水平，通常要求 Precision ≥ 95% 且 Recall ≥ 95%。

## 教学建议

1. **"警察抓小偷"类比法**：用生活化场景帮助学员理解抽象概念
2. **可视化教学**：在一张图片上分别标出 TP、FP、FN 的位置，用不同颜色高亮
3. **互动练习**：展示标注结果，让学员判断实例属于 TP、FP 还是 FN
