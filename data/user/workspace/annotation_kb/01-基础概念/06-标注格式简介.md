# 标注格式简介

不同标注工具和训练框架使用不同的标注文件格式进行数据交换。掌握常见标注格式及其之间的转换规则，是标注工程师的基本功。

## 一、图像标注格式

### 1. Pascal VOC（XML 格式）

VOC 格式是计算机视觉领域最经典的标注格式之一，使用 XML 文件存储。

**适用场景：** 目标检测
**文件扩展名：** `.xml`
**坐标类型：** 绝对像素坐标，xmin / ymin（左上角）和 xmax / ymax（右下角）
**关键字段：** filename, size（图片宽高深度）, object（name, bndbox, difficult, truncated）

### 2. COCO JSON

COCO（Common Objects in Context）格式是当前目标检测和分割任务最广泛使用的格式，使用单个 JSON 文件存储所有标注信息。

**适用场景：** 目标检测、实例分割、关键点检测、图像字幕
**文件扩展名：** `.json`
**关键结构：**
- `images`：图片信息（id, file_name, width, height）
- `annotations`：标注信息（image_id, category_id, bbox [x, y, w, h], segmentation, area, iscrowd）
- `categories`：类别信息（id, name, supercategory）
**坐标类型：** 绝对像素坐标，bbox 格式为 [x, y, width, height]（左上角 + 宽高）

### 3. YOLO（TXT 格式）

YOLO 格式专为 YOLO 系列目标检测算法设计，使用纯文本格式，简洁高效。

**适用场景：** 目标检测
**文件扩展名：** `.txt`
**每张图片对应一个 txt 文件，每行一个目标：**
```
class_id x_center y_center width height
```
**坐标类型：** 归一化坐标（所有值除以图片宽高后，范围为 0 到 1）
**配套文件：** classes.txt（类别名称列表，一行一个类别名，按 class_id 顺序排列）

### 4. LabelMe JSON

LabelMe 是麻省理工学院开发的开源标注工具，使用 JSON 格式存储多边形标注信息。

**适用场景：** 语义分割、实例分割、多边形标注
**文件扩展名：** `.json`
**关键字段：** imagePath, imageHeight, imageWidth, shapes（label, points 多边形顶点坐标列表, shape_type）

### 5. CreateML JSON（Apple 生态）

Apple 用于 iOS / macOS 模型训练的标注格式。

**适用场景：** 目标检测（Core ML）
**文件扩展名：** `.json`
**关键字段：** annotations（label, coordinates {x, y, width, height}）

## 二、常用格式转换对照

### VOC → COCO
```
COCO_x = VOC_xmin
COCO_y = VOC_ymin
COCO_width = VOC_xmax - VOC_xmin
COCO_height = VOC_ymax - VOC_ymin
```

### COCO → YOLO
```
x_center = (COCO_x + COCO_width / 2) / img_width
y_center = (COCO_y + COCO_height / 2) / img_height
width = COCO_width / img_width
height = COCO_height / img_height
```

### YOLO → VOC
```
xmin = (x_center - width / 2) * img_width
ymin = (y_center - height / 2) * img_height
xmax = (x_center + width / 2) * img_width
ymax = (y_center + height / 2) * img_height
```

## 三、坐标系注意事项

- **坐标原点**：大多数标注格式以图片左上角为原点 (0, 0)，x 轴向右，y 轴向下
- **坐标边界**：坐标值不能为负数，不能超出图片宽度和高度
- **归一化 vs 绝对坐标**：YOLO 使用归一化坐标，其他格式多为绝对像素坐标
