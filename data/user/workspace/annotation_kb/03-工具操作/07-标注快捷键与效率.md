# 标注快捷键与效率提升

熟练使用键盘快捷键是标注员从"会用工具"到"高效标注"的分水岭。掌握快捷键可将标注速度提升 2-3 倍。

## Label Studio 快捷键

### 基础操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| 1-9 数字键 | 选择对应序号的标签 | 最常用的快捷键，按标签顺序绑定 |
| Esc | 取消当前绘制 | 放弃正在绘制的框或多边形 |
| Delete / Backspace | 删除选中标注 | 删除当前选中的标注框/多边形/关键点 |
| Ctrl + Enter | 提交当前任务 | 标注完成，跳转到下一个任务 |
| Ctrl + Z | 撤销 | 撤销上一步操作 |
| Ctrl + Shift + Z | 重做 | 恢复被撤销的操作 |
| Ctrl + S | 保存草稿 | 保存当前进度（不提交，可后续继续） |

### 选框操作

| 快捷键 | 功能 |
|--------|------|
| ↑ ↓ ← → | 微调选框位置（每次移动 1 像素） |
| Shift + ↑ ↓ ← → | 快速移动（每次移动 10 像素） |
| Ctrl + C / Ctrl + V | 复制/粘贴标注框（同类目标批量标注） |
| Ctrl + D | 复制当前框并偏移（快速标注多个同类目标） |
| 鼠标滚轮 | 缩放图片 |
| 按住空格 + 拖动 | 平移图片 |

### 批量操作

| 快捷键 | 功能 |
|--------|------|
| Ctrl + A | 全选所有标注框 |
| 按住 Shift + 点击 | 多选标注框 |
| Ctrl + G | 将选中的框编组 |
| Ctrl + Shift + G | 解散编组 |

## 效率提升实战技巧

### 技巧一：固定操作姿势

左手始终放在键盘左侧（ASDF 区域），右手操作鼠标。这种姿势确保：
- 左手快速切换标签数字键和工具快捷键
- 右手精准控制鼠标进行画框和选框操作
- 双手分工明确，减少手部移动时间

### 技巧二：按标签分批标注

不要在一张图片上来回切换标签标注不同类别。推荐流程：
1. 先扫描图片，辨识所有目标
2. 选择第一个标签（如 car），标注所有汽车
3. 切换到第二个标签（如 person），标注所有行人
4. 重复直到完成

这种方式减少了标签切换次数，每切换一次浪费约 2 秒，一天标注 500 张可节省 15 分钟以上。

### 技巧三：由大到小标注

先标注大目标后标注小目标。原因：
- 大目标更醒目，容易在扫描时发现
- 小目标常常在大目标附近或内部，先标完大目标后可以集中精力寻找小目标
- 减少漏标：大目标标完后，剩余未标注的区域更容易判断是背景还是小目标

### 技巧四：善用缩放

- **全局视图（缩小）**：快速浏览，了解图片整体布局
- **精细标注（放大）**：小目标和边缘模糊的目标放大标注
- 每张图的标注顺序：缩小浏览 → 放大大目标标注 → 放大扫描小目标 → 缩小复查

### 技巧五：批量操作 + 复制粘贴

对于大量重复操作：
- 同类目标大小相近：标注一个 → Ctrl+D 复制到其他位置 → 微调位置和大小
- 视频标注：标注关键帧 → 跳过直接调整末端关键帧 → 微调中间帧

### 技巧六：阶段性休息

- 连续标注 45-50 分钟后强制休息 5-10 分钟
- 休息时闭眼远眺：缓解眼疲劳
- 起身活动：缓解颈椎和手腕压力
- 研究显示，疲劳会导致准确率下降 10%-15%
