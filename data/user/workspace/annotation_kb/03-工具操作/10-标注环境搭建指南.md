# 标注环境搭建指南

标注环境的搭建直接影响标注效率和质量。本文从个人学习到企业级团队标注，提供分层次的搭建方案。

## 一、最简环境（个人学习）

**适用场景：** 一人使用、学习标注基础操作、小型课程作业

### 方案：Label Studio 本地安装

**步骤 1：安装 Python**

确保系统已安装 Python 3.8 及以上版本：
```bash
python --version  # 应输出 Python 3.8+
```

**步骤 2：安装 Label Studio**

```bash
pip install label-studio
```

**步骤 3：启动服务**

```bash
label-studio start --port 8080
```

浏览器访问 `http://localhost:8080`，注册账号后即可使用。

**硬件要求：**
- CPU：2 核及以上
- 内存：4GB RAM（推荐 8GB）
- 存储：10GB 可用空间
- 显卡：不需要

**数据存储：** Label Studio 默认使用 SQLite 存储，数据文件位于用户目录下的 `.label-studio` 文件夹。适合个人使用，但不支持多用户并发。

**优点：** 安装简单、即装即用、无需网络
**缺点：** 不可多人协作、数据存储在本地

## 二、团队共享环境（3-10 人）

**适用场景：** 小型标注团队、教学班级、课程实训

### 方案：服务器部署 Label Studio / CVAT + 浏览器访问

**方案 A：Label Studio 服务端部署**

在一台服务器（或云主机）上安装 Label Studio，团队成员通过浏览器访问。

**步骤 1：准备服务器**

推荐云主机配置（阿里云 / 腾讯云 / AWS）：
- CPU：4 核
- 内存：16GB RAM
- 存储：100GB SSD 系统盘 + 200GB 数据盘
- 操作系统：Ubuntu 22.04 LTS
- 带宽：5 Mbps 及以上

**步骤 2：部署 Label Studio**

```bash
# SSH 登录服务器
ssh user@server-ip

# 安装 Python 和 pip
sudo apt update
sudo apt install python3 python3-pip python3-venv -y

# 创建专用目录
mkdir /opt/labelstudio
cd /opt/labelstudio

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装 Label Studio
pip install label-studio

# 配置数据库（使用 PostgreSQL 替代 SQLite）
pip install psycopg2-binary

# 启动服务（使用 systemd 持久化运行）
sudo tee /etc/systemd/system/labelstudio.service << EOF
[Unit]
Description=Label Studio Service
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/opt/labelstudio
ExecStart=/opt/labelstudio/venv/bin/label-studio start --port 8080 --host 0.0.0.0
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable labelstudio
sudo systemctl start labelstudio
```

**步骤 3：配置防火墙和域名**

```bash
# 开放 8080 端口（或配置 Nginx 反向代理使用 80/443 端口）
sudo ufw allow 8080/tcp
```

团队成员访问 `http://服务器IP:8080` 即可使用。

**方案 B：CVAT Docker 部署**

```bash
# 安装 Docker
sudo apt update
sudo apt install docker.io docker-compose-v2 -y
sudo usermod -aG docker $USER

# 克隆 CVAT 仓库
git clone https://github.com/openvinotoolkit/cvat
cd cvat

# 启动服务
docker compose up -d

# 创建超级用户
docker exec -it cvat_server bash -c 'python3 ~/manage.py createsuperuser'
```

## 三、企业级环境（10+ 人）

**适用场景：** 大型标注项目、专业标注团队、企业数据管理

### 核心架构

```
用户浏览器 → Nginx（负载均衡） → Label Studio / CVAT 应用服务器
                                        ↓
                                  PostgreSQL（数据库）
                                        ↓
                               MinIO / S3（对象存储）
                                        ↓
                              Redis（缓存 + 任务队列）
```

### 组件说明

**1. Web 服务器（Nginx）**
- 反向代理 + 负载均衡
- HTTPS 证书管理（Let's Encrypt）
- 静态文件缓存
- 限流和防攻击

**2. 数据库（PostgreSQL）**

Label Studio 默认使用 SQLite，生产环境必须切换为 PostgreSQL：

```bash
# 安装 PostgreSQL
sudo apt install postgresql postgresql-contrib -y

# 创建数据库和用户
sudo -u postgres psql -c "CREATE DATABASE labelstudio;"
sudo -u postgres psql -c "CREATE USER lsuser WITH PASSWORD 'your_password';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE labelstudio TO lsuser;"
```

启动 Label Studio 时指定数据库：
```bash
export DATABASE_URL=postgresql://lsuser:password@localhost/labelstudio
label-studio start --port 8080
```

**3. 对象存储（MinIO / S3）**

大规模图片/视频存储在对象存储中，而不是应用服务器本地磁盘：

```bash
# 部署 MinIO（S3 兼容的对象存储）
docker run -d --name minio \
  -p 9000:9000 -p 9001:9001 \
  -v /data/minio:/data \
  -e MINIO_ROOT_USER=admin \
  -e MINIO_ROOT_PASSWORD=your_password \
  minio/minio server /data --console-address ":9001"
```

在 Label Studio 中配置云存储：Settings → Cloud Storage → Add Source → S3（填写 MinIO 的 endpoint、access key、secret key 和 bucket 名称）。

**4. 缓存和队列（Redis）**

```bash
sudo apt install redis-server -y
```

配置 Label Studio 使用 Redis 作为任务队列，提升大项目导出性能。

## 四、教学环境推荐方案

### 课堂实训场景

**推荐配置：**
- 老师在一台云服务器上部署 Label Studio
- 学生通过浏览器访问（无需安装任何软件）
- 老师通过管理员账号统一管理任务和数据

**操作步骤：**
1. 课前：老师创建项目、上传图片、配置标注界面
2. 课上：学生用自己的浏览器登录，每人随机分配到一批任务
3. 课中：老师在管理界面实时查看每个学生的标注进度和质量
4. 课后：老师导出所有标注结果，统一评分

### 学生自主练习场景

**推荐配置：**
- 每个学生在自己电脑上运行 `pip install label-studio`
- 所有标注数据和个人练习结果存储在本地
- 通过实践作业的形式提交标注结果文件

## 五、环境检查清单

部署完成后，检查以下项目确保环境就绪：

- [ ] Label Studio / CVAT 服务正常启动，浏览器可访问
- [ ] 创建测试项目，导入 5 张测试图片
- [ ] 完成 1 张标注、提交，确认标注结果正确保存
- [ ] 导出标注结果，确认 JSON 文件完整
- [ ] 多用户分别登录，确认任务分配不冲突
- [ ] 防火墙和安全组策略已配置（仅开放必要端口）
- [ ] 数据定期备份已配置（数据库每日备份 + 文件存储快照）

**参考：** https://labelstud.io/guide/install.html
