# 标注工具选型指南

选择正确的标注工具是项目成功的第一步。工具有错配会导致效率低下、质量下降甚至项目返工。

## 选型决策框架

选择标注工具时应从以下五个维度综合评估：

1. **数据类型**：标注什么？（图片/视频/文本/音频/3D点云）
2. **任务类型**：怎么标？（分类/检测/分割/关键点/NER/关系抽取）
3. **团队规模**：多少人参与？（个人 < 3 人 < 小团队 3-10 人 < 大团队 10+ 人）
4. **预算限制**：免费还是付费？（开源 vs 商业版）
5. **技术能力**：团队技术水平如何？（是否需要部署服务器、编写配置、开发脚本）

## 按项目规模选型

### 个人 / 教学项目（< 3 人）

**首选：Label Studio**
- 安装简单：`pip install label-studio` 一行命令
- 界面友好：中文本地化好，学习曲线平缓
- 功能完备：支持 30+ 种标注模板
- 免费：社区版完全免费

**备选：Makesense.ai**
- 无需安装，浏览器打开即用
- 适合偶尔标注少量图片的教学演示

### 小团队（3-10 人）

**首选：Label Studio（服务端部署）**
- 在服务器上安装 Label Studio，团队成员浏览器访问
- 支持任务自动分配和数据统一管理
- MySQL/PostgreSQL 替代默认 SQLite 以支持并发

**备选：CVAT**
- 如果需要视频标注或 AI 辅助标注
- 需要 Docker 部署技能

### 大型团队（10+ 人）

**首选：CVAT Enterprise / Label Studio Enterprise**
- 完善的团队管理（角色权限、任务分配、评审工作流）
- 高性能（支持大规模数据存储和多人并发）
- 企业级支持（SLA、安全审计、私有化部署）

**商业平台备选：**
- **SuperAnnotate**：专注于标注质量管控和项目管理
- **Scale AI / Labelbox**：提供标注+质检外包一体化服务

## 按标注任务类型选型

| 任务类型 | 推荐工具 | 理由 |
|---------|---------|------|
| 图像分类 | Label Studio / VGG Image Annotator | 简单易用、配置方便 |
| 目标检测（矩形框） | Label Studio / CVAT / LabelImg | 三大主流工具均支持 |
| 实例分割（多边形） | CVAT / Label Studio | 多边形工具完善 |
| 语义分割（像素级） | Label Studio / 3D Slicer | Brush 笔刷标注 |
| 关键点标注 | CVAT / Label Studio | 关键点模板丰富 |
| 视频目标跟踪 | CVAT | 插值标注、帧间跟踪 |
| 3D 点云标注 | CVAT / SUSTechPOINTS | 3D 视图专业支持 |
| 文本分类/NER | Doccano / Label Studio | 中文 NLP 支持好 |
| 音频标注 | Audacity / Label Studio | 音频分类和区间标注 |

## 教学场景推荐方案

### 入门阶段（学习标注概念）

**工具：Label Studio**
- 学习目标：理解标注任务的基本概念（任务、标注配置、标注、预测）
- 操作练习：图像分类（10 张）→ 目标检测（20 张）→ 多边形分割（10 张）
- 时长：2-3 课时

### 进阶阶段（体验专业工作流）

**工具：CVAT**
- 学习目标：理解团队标注工作流（任务分配、质检、评审）
- 操作练习：视频标注（体验插值标注）、AI 辅助标注
- 时长：2-4 课时

### 高级阶段（理解标注数据结构）

**工具：Python + Label Studio API**
- 学习目标：理解标注数据的 JSON 结构、格式转换、批量处理
- 编程练习：解析 COCO JSON → 计算标注统计 → 格式转换（COCO → YOLO → VOC）
- 时长：3-5 课时
