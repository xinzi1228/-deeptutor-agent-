# 数据格式转换工具

标注项目常常需要在不同数据格式之间转换以满足不同模型训练框架的需求。本文将介绍常用格式转换方法和工具。

## 常见标注格式简介

### VOC XML 格式

Pascal VOC 挑战赛定义的格式，使用 XML 文件存储每个图片的标注信息：

```xml
<annotation>
  <filename>001.jpg</filename>
  <size>
    <width>1920</width>
    <height>1080</height>
    <depth>3</depth>
  </size>
  <object>
    <name>car</name>
    <bndbox>
      <xmin>100</xmin><ymin>150</ymin>
      <xmax>400</xmax><ymax>350</ymax>
    </bndbox>
  </object>
</annotation>
```

坐标使用绝对像素值，坐标原点为图片左上角。

### COCO JSON 格式

Microsoft COCO 数据集格式，所有图片的标注存储在一个 JSON 文件中：

```json
{
  "images": [{"id": 1, "file_name": "001.jpg", "width": 1920, "height": 1080}],
  "annotations": [
    {
      "id": 1, "image_id": 1, "category_id": 1,
      "bbox": [100, 150, 300, 200],
      "area": 60000
    }
  ],
  "categories": [{"id": 1, "name": "car"}]
}
```

`bbox` 格式为 `[x, y, width, height]`。

### YOLO TXT 格式

每个图片对应一个同名的 txt 文件，每行表示一个标注框：

```
0 0.1302 0.2315 0.1563 0.1852
```

格式为 `class_id x_center y_center width height`，所有坐标都归一化到 0-1 范围。

## Python 脚本转换

### VOC → COCO

```python
def voc_bbox_to_coco(voc_bbox):
    """VOC [xmin, ymin, xmax, ymax] → COCO [x, y, w, h]"""
    xmin, ymin, xmax, ymax = voc_bbox
    x = xmin
    y = ymin
    w = xmax - xmin
    h = ymax - ymin
    return [x, y, w, h]
```

### COCO → YOLO

```python
def coco_bbox_to_yolo(coco_bbox, img_w, img_h):
    """COCO [x, y, w, h] → YOLO [x_center, y_center, width, height]（归一化）"""
    x, y, w, h = coco_bbox
    x_center = (x + w / 2) / img_w
    y_center = (y + h / 2) / img_h
    norm_w = w / img_w
    norm_h = h / img_h
    return [x_center, y_center, norm_w, norm_h]
```

### YOLO → VOC

```python
def yolo_bbox_to_voc(yolo_bbox, img_w, img_h):
    """YOLO（归一化）→ VOC [xmin, ymin, xmax, ymax]（绝对像素）"""
    x_center, y_center, norm_w, norm_h = yolo_bbox
    x = (x_center - norm_w / 2) * img_w
    y = (y_center - norm_h / 2) * img_h
    w = norm_w * img_w
    h = norm_h * img_h
    return [int(x), int(y), int(x + w), int(y + h)]
```

## 在线转换工具

### Roboflow

[Roboflow](https://roboflow.com) 是在线数据集管理平台，提供：
- 标注格式双向转换（支持 30+ 格式）
- 数据增强（旋转、翻转、色彩调整、噪声添加等）
- 数据集预处理和版本管理
- 与 YOLO、TensorFlow、PyTorch 等框架的直接集成

使用流程：上传数据集 → 选择预处理和数据增强 → 选择目标格式 → 下载转换后的数据。

### Makesense.ai

在线标注工具 [Makesense.ai](https://www.makesense.ai) 支持：
- 直接在浏览器中标注图片
- 导出 VOC XML、YOLO TXT、CSV 等多种格式
- 无需安装、无需注册

适合快速标注少量数据或教学演示。

## 格式转换注意事项

### 坐标系统差异

| 格式 | 坐标原点 | 坐标范围 | bbox 表示 |
|------|---------|---------|-----------|
| VOC XML | 左上角 (0,0) | 绝对像素值 | [xmin, ymin, xmax, ymax] |
| COCO JSON | 左上角 (0,0) | 绝对像素值 | [x, y, width, height] |
| YOLO TXT | — | 归一化 [0,1] | [x_center, y_center, width, height] |

### 类别映射问题

不同数据集的类别 ID 表不同。例如数据集 A 中 `car=0, person=1`，数据集 B 中 `car=1, person=0`。格式转换时必须重新映射类别 ID，建议维护统一的类别映射表。

### 坐标精度

- YOLO 格式归一化后建议保留 6 位小数，确保足够精度
- 从归一化坐标还原时注意四舍五入误差，可能造成 ±1 像素偏差
- 大规模转换前建议使用小样本验证（取 10 张图转换后人工抽查）
