# 预标注与辅助标注

预标注（Pre-labeling / Pre-annotation）是利用已有 AI 模型对待标注数据自动生成初步标注结果，人工只需审核和修正，从而大幅提升标注效率。

## 预标注工作流程

```
原始数据 → AI模型推理 → 预标注结果 → 标注员审核修正 → 最终标注结果
                ↑                          |
                └────── 反馈优化 ────────────┘
```

与从零标注相比，预标注可将标注效率提升 50%-80%，尤其在目标检测、语义分割等密集标注任务中效果显著。

## 预标注实现方式

### 方式一：Label Studio ML Backend

Label Studio 通过 ML Backend 插件支持预标注：

```bash
# 安装 ML Backend
pip install label-studio-ml

# 启动目标检测后端（以 YOLO 为例）
label-studio-ml init yolo_backend --script /path/to/yolo_detector.py
label-studio-ml start yolo_backend
```

配置 Label Studio 项目连接 ML Backend：
1. 项目 Settings → Machine Learning → Add Model
2. 填写 ML Backend URL（如 `http://localhost:9090`）
3. 勾选"Use for interactive preannotations"

### 方式二：CVAT 内置 AI 工具

CVAT 通过 Nuclio 服务器提供内置 AI 辅助：

```bash
# 部署 Nuclio + OpenVINO 模型
docker compose -f docker-compose.yml -f components/serverless/docker-compose.serverless.yml up -d
```

AI 工具包括：
- **Detectors**：自动目标检测（支持 YOLO、Faster R-CNN、SSD 等）
- **Trackers**：视频目标跟踪（SiamMask、DeepSORT 等）
- **Interactors**：点击目标后智能贴合框（Mask R-CNN 等）

### 方式三：Python 脚本离线预标注

对于灵活性要求高的项目，可以使用 Python 脚本离线生成预标注结果：

```python
import json
from ultralytics import YOLO

model = YOLO("yolov8x.pt")  # 加载预训练模型
predictions = []

for img_path in image_list:
    results = model(img_path)
    pred_result = []
    for box in results[0].boxes:
        x1, y1, x2, y2 = box.xyxy[0].tolist()
        cls_id = int(box.cls[0])
        label = label_map[cls_id]
        pred_result.append({
            "original_width": results[0].orig_shape[1],
            "original_height": results[0].orig_shape[0],
            "value": {
                "x": x1, "y": y1,
                "width": x2 - x1, "height": y2 - y1,
                "rectanglelabels": [label]
            },
            "type": "rectanglelabels"
        })
    predictions.append({
        "data": {"image": img_path},
        "predictions": [{"result": pred_result}]
    })

with open("pre_labels.json", "w", encoding="utf-8") as f:
    json.dump(predictions, f, ensure_ascii=False, indent=2)
```

然后将 `pre_labels.json` 导入 Label Studio。

## 预标注模型选择指南

| 任务类型 | 推荐模型 | 特点 |
|---------|---------|------|
| 通用目标检测 | YOLOv8/v9 | 速度快（FPS > 100），精度高 |
| 高精度检测 | Faster R-CNN / DETR | 精度优先，速度较慢 |
| 实例分割 | YOLOv8-seg / Mask R-CNN | 像素级分割 |
| 通用分割 | SAM（Meta Segment Anything Model） | 零样本分割，适应性强 |
| 关键点检测 | HRNet / OpenPose / YOLOv8-pose | 人体姿态关键点 |
| 文本检测 | PaddleOCR / DBNet | 文字区域检测 |
| 面部检测 | RetinaFace / YOLOv8-face | 面部框+关键点 |

## 辅助标注功能

### 自动框贴合

在 CVAT 中使用 Interactor 工具：点击目标 → AI 自动计算并生成贴合目标的框。相比手动画框，可节省 40% 时间。

### 视频插值标注

CVAT 核心功能：标注员标注视频的第 1 帧和第 N 帧 → 系统自动补全中间帧的标注。操作步骤：
1. 在第 1 帧绘制目标框
2. 跳转到第 N 帧，调整框位置
3. 系统自动生成中间帧的线性插值标注
4. 标注员仅需微调部分帧

### 批量同类物体标注

部分标注工具支持"同类批量标注"：标注员手动标几个同类物体后，AI 自动识别和标注剩余的同类物体。

## 预标注注意事项

### 必须人工审核

预标注结果必须经过人工审核，特别是以下场景：
- **小目标**（面积 < 32×32 像素）：模型漏检率高
- **密集目标**（多个目标重叠/重叠度 > 50%）：模型容易将一个目标识别为多个
- **遮挡目标**（可见比例 < 50%）：模型识别困难
- **罕见类别**（训练数据少）：模型对该类别精度低

### 建立校准机制

- 首次使用预标注模型的全新标注类型，先全量人工检查 100 张
- 根据检查结果估算模型在该数据集上的精确率和召回率
- 如模型精度 < 80%，不建议使用预标注（修正成本可能高于从头标注）
- 定期对比预标注结果和最终标注结果，持续优化模型

### 格式兼容性

- 预标注输出格式必须与标注工具兼容
- 预标注结果的坐标系统需与标注工具一致（绝对像素 vs 归一化）
- 标签名称需与标注工具的 Labeling Config 中的标签名称完全一致
