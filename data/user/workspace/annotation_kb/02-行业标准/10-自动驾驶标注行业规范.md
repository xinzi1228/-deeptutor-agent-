# 自动驾驶标注行业规范

自动驾驶是数据标注需求量最大的行业应用领域之一，也是标注精度要求最高的领域。自动驾驶系统的安全性直接依赖于标注数据的质量和准确性，因此该行业有严格的标注规范和精度要求。

## 一、自动驾驶的主要标注类型

### 1.1 2D 目标检测（2D Object Detection）

**标注内容：** 在摄像头图像中用 2D 矩形框标注各类道路目标。

**主要类别：**

| 类别 | 标注要点 |
|------|---------|
| 车辆 | 小汽车、卡车、公交车、摩托车 —— 完整车身，含后视镜 |
| 行人 | 从头顶到脚底完整标注，含不同姿态（行走、站立、蹲下） |
| 骑行者 | 骑自行车/电动车的人 + 车辆作为整体标注 |
| 交通标志 | 紧贴标志牌本身，不包括立杆 |
| 交通灯 | 灯体本身，标注状态（红/黄/绿/灭） |

**精度要求：**
- IOU ≥ 0.7（一般目标）
- 行人和交通灯等安全关键目标 IOU ≥ 0.85
- 目标检测准确率 ≥ 95%，召回率 ≥ 95%

### 1.2 车道线检测（Lane Detection）

**标注内容：** 道路上的各种车道标记线。

**分类维度：**

| 维度 | 类别 |
|------|------|
| 颜色 | 白色、黄色、蓝色、其他 |
| 类型 | 实线、虚线、双实线、双虚线、虚实组合 |
| 功能 | 同向车道分隔线、对向车道分隔线、道路边缘线、导流线 |

**精度要求：** 像素级精度（≤ 5 像素偏差），mIOU ≥ 0.9

### 1.3 可行驶区域（Drivable Area / Free Space）

**标注内容：** 车辆当前可以安全行驶的道路区域（语义分割任务）。

**标注规则：**
- 不包括人行道、绿化带、隔离带等不可行驶区域
- 包括交叉路口、停车场等可通行区域
- 对于被前车遮挡的道路区域，如果确定是可行驶区域仍需标注

**精度要求：** mIOU ≥ 0.90

### 1.4 3D 目标检测（3D Object Detection）

**标注内容：** 融合激光雷达（LiDAR）点云数据和摄像头图像，标注目标在三维空间中的 3D 边界框（Cuboid）。

**3D 框的 7 个自由度参数：**
- 中心点坐标：(x, y, z)
- 尺寸：(length, width, height)
- 朝向角：yaw（偏航角，绕 Z 轴旋转）

**精度要求：** 3D IOU ≥ 0.5，中心点位置偏差 < 0.3 米

### 1.5 交通灯检测与状态标注

交通灯是自动驾驶中最关键的安全信号之一，需要极高的标注精度。

**标注内容：**
- 交通灯边界框位置
- 交通灯状态：红灯（red_stop / red_flashing）/ 黄灯（yellow）/ 绿灯（green）/ 熄灭（off）

**精度要求：** 准确率 ≥ 99%，任何交通灯的错误标注都可能导致自动驾驶系统的致命错误。

## 二、特殊场景处理规范

### 2.1 恶劣天气场景

自动驾驶必须在各种天气条件下安全工作，因此标注数据必须覆盖恶劣天气场景：

**特殊标注要求：**
- **夜间**：正常标注，但标注员需更仔细分辨低光照下的目标
- **雨/雪**：正常标注被雨雪部分遮挡但仍可识别的目标；严重遮挡无法分辨的不标注
- **雾天**：仅标注可视范围内可分辨的目标
- **反光/眩光**：因反光无法分辨的目标区域不标注

### 2.2 密集交通场景

城市拥堵路段的密集交通场景是标注难点：
- 多辆车紧密排列时，逐辆分开标注
- 远处的密集车辆群体如果个体无法分辨，标记为 `traffic_dense_area`
- 行人密集区域（如人行横道）每个可分辨的行人必须单独标注

### 2.3 特殊交通参与者

| 类型 | 标注类别 | 说明 |
|------|---------|------|
| 轮椅使用者 | 行人或单独类别 | 行为模式与行人不同 |
| 婴儿车 | 行人或单独类别 | 推婴儿车的行人 |
| 动物（狗、猫、鹿等） | 动物类别 | 农村/郊区道路常见 |
| 工程车辆/特种车辆 | 车辆子类 | 洒水车、扫地车、挖掘机等 |
| 临时路障（锥桶/水马/施工围栏） | 障碍物类别 | 施工区常见 |

## 三、国际主流自动驾驶数据集

### Waymo Open Dataset

- 发布方：Waymo（Google 旗下自动驾驶公司）
- 数据量：1150 个场景，每个场景 20 秒，包含摄像头图像和激光雷达点云
- 标注类型：3D 检测框、2D 检测框、跟踪
- 参考：https://waymo.com/open/

### nuScenes Dataset

- 发布方：Motional（Aptiv）
- 数据量：1000 个场景，6 个摄像头 + 1 个激光雷达
- 标注类型：3D 检测框、属性（行人姿态、车辆类型、交通灯状态等）
- 参考：https://www.nuscenes.org/

### KITTI Dataset

- 发布方：卡尔斯鲁厄理工学院
- 数据量：约 15000 个标注帧
- 标注类型：2D 检测、3D 检测、车道线、里程计
- 参考：http://www.cvlibs.net/datasets/kitti/

| 工具 | 适用场景 | 特点 |

| Scale AI | 企业级标注平台 | 支持大规模标注项目管理和质量控制 |

### 3D 标注工具

| 工具 | 适用场景 | 特点 |
|------|---------|------|
| CloudCompare | 点云可视化/标注 | 开源，适合小批量点云标注 |
| SUSTechPOINTS | 点云标注 | 轻量开源，支持 3D 框和分割 |
| LatticeFlow | 企业级 3D 标注 | 支持大规模点云标注和质检 |

## 五、教学要点

在标注教学中，自动驾驶标注是重要的行业应用专题：

1. **2D vs 3D 对比**：让学员从 2D 标注入门，逐步理解 3D 标注的差异和挑战
2. **安全第一的理念**：强调行人、交通灯等安全相关目标的极高精度要求
3. **多传感器融合认知**：让学员了解摄像头和激光雷达在自动驾驶中的互补角色
4. **数据集对比练习**：用 Waymo 和 nuScenes 的标注规范分别标注同类场景，体会不同标准间的差异
