# 标注数据交付标准

标注数据交付是标注项目的最终环节，交付质量直接影响客户满意度和项目验收结果。GB/T 41867-2022 §6.3 对标注数据的交付标准做出了明确规定。

## 一、交付数据完整性

### 1.1 数据文件完整性

- 标注文件（XML/JSON/TXT）与原始数据文件（图片/文本/音频）必须**一一对应**，保证无遗漏、无多余
- 标注文件与原始数据文件的命名应保持一致（同名，仅扩展名不同），确保可自动配对
- 类别定义文件（classes.txt / categories.json）完整且经过最终确认
- 数据集划分文件（train/val/test split）明确清晰

### 1.2 交付数据检查清单

| 检查项 | 检查方法 | 合格标准 |
|--------|---------|---------|
| 图片与标注对应 | 遍历比对文件名 | 100% 一一对应 |
| 标注文件可解析性 | 用解析器批量读取 | 100% 解析通过 |
| 类别总数一致性 | 统计标注中出现类别 vs 定义文件 | 一致 |
| 坐标值合法性 | 检查坐标范围与偏移 | 无越界/负值 |
| 无空标注文件 | 检查文件大小 | 无 0 字节标注文件 |

## 二、标注数据准确性

### 2.1 核心准确率要求

| 类别 | 准确率要求 | 说明 |
|------|-----------|------|
| 关键类别（如行人、车辆） | ≥ 95% | 对模型训练影响最大的核心类别 |
| 非关键类别 | ≥ 90% | 次要类别可稍放宽要求 |
| 安全相关类别（自动驾驶） | ≥ 99% | 安全攸关的类别误标率必须极低 |

### 2.2 准确率计算方法

准确率基于质检抽检结果计算：

```
准确率 = 合格标注数 / 抽检标注总数 × 100%
```

其中，"合格"的判定标准取决于标注类型：
- **目标检测**：IOU ≥ 0.5 且类别正确
- **分类标注**：标签完全正确
- **分割标注**：mIOU ≥ 0.7
- **关键点标注**：点偏移距离 ≤ 阈值（通常为图片对角线长度的 2%）

### 2.3 一致性检验

交付前必须在不同标注员之间进行标注一致性检验：
- Cohen's Kappa / Fleiss' Kappa ≥ 0.8
- 低于 0.8 的批次需要进行质量回溯并重新标注有争议的部分

## 三、标注数据规范性

### 3.1 文件命名规范

统一使用以下命名规则：
- 图片文件：`{项目代号}_{批次}_{序号}.jpg`（如 `AD_20250601_001234.jpg`）
- 标注文件：`{项目代号}_{批次}_{序号}.json`（与图片同名不同扩展名）
- 命名中不使用特殊字符（空格、中文、括号等），只使用大小写字母、数字和下划线

### 3.2 标注格式校验

交付前必须对所有标注文件进行格式校验：

**JSON 格式校验：**
- JSON 语法正确（括号匹配、引号闭合、无多余逗号）
- 必填字段完整（image_id, category_id, bbox/segmentation 等）
- 字段类型正确（坐标值为数字不是字符串，类别 ID 为整数）
- 文件不是空文件或非 JSON 文件

**XML 格式校验：**
- XML 语法正确（标签闭合、属性引号匹配）
- 使用 XSD Schema 验证结构和字段完整性
- 坐标值在有效范围内（xmin < xmax, ymin < ymax）

### 3.3 类别名称清晰性

- 类别名称含义明确，无歧义
- 不使用含混的命名（如 `object_1`、`type_A` 等无意义的代号）
- 如有缩写，需在类别定义文档中给出全称

## 四、交付物清单

一个完整的标注项目交付应包含以下内容：

| 序号 | 交付物 | 内容说明 |
|------|--------|---------|
| 1 | 原始数据文件夹 | 包含所有待标注的原始数据（图片、文本、音频等） |
| 2 | 标注文件文件夹 | 包含所有标注结果文件，与原始数据一一对应 |
| 3 | 类别定义文档 | 每个类别的名称、含义说明、正反示例截图 |
| 4 | 标注规范说明书 | 完整的标注规则文档，包括特殊场景处理说明和修订记录 |
| 5 | 质检报告 | 抽检率、准确率、漏标率、错标率、Kappa 系数、返工记录 |
| 6 | 数据集划分配置 | train/val/test 的划分规则和文件列表 |
| 7 | 项目完结确认书 | 双方签字确认的项目交付清单 |

## 五、交付验收流程

1. **提交交付物清单**：标注服务方提交完整交付物给客户方
2. **数据完整性检查**：客户方检查数据文件和文件夹结构是否完整
3. **数据准确性抽查**：客户方随机抽取 5%-10% 的样本进行复核
4. **格式规范性检查**：验证标注文件格式是否合法、可解析
5. **签署验收报告**：验收通过后双方签署项目验收报告
6. **数据销毁确认**：标注服务方按规定销毁本地数据副本
