# 质检流程设计

质检流程是保障标注数据质量的核心机制。一个设计良好的质检流程能够在控制成本的前提下，最大化标注数据的准确性。

## 三级质检体系

```
一级质检（自检） → 二级质检（抽检） → 三级质检（仲裁）
       ↑                 ↑                  ↑
   标注员本人        专职质检员          专家团队
```

### 第一级：标注员自检

标注员完成一批标注任务后（通常 30-50 张为一批），在提交之前逐张自查。

**自检检查项：**
1. **完整性**：是否所有要求的标注类型都已标注？（如要求同时标注汽车和行人，两类都不应遗漏）
2. **准确性**：每个框的标签是否正确？框是否紧贴目标边缘？
3. **一致性**：同类目标的标注方式是否一致？（如所有汽车的框都是以最小外接矩形框选的）

**自检工具：**
- Label Studio 的标注列表视图：可快速浏览所有标注框
- CVAT 的标注预览模式：可高亮显示所有框

**自检原则：** 标注员对待自己标注的数据要保持"批判性思维"——假设自己是质检员，去挑自己标注的毛病。

### 第二级：质检员抽检

标注员提交后，专职质检员对标注结果进行抽查。

**抽检流程：**
1. 质检员从标注员提交的批次中按比例随机抽取样本
2. 逐张比对标注结果与原始图片，检查是否存在错误
3. 记录错误类型和具体位置
4. 给出该批次的质量评分

**通过标准：**
- 错误率 ≤ 5%：批次通过，标注结果入库
- 错误率 5%-10%：批次退回返工，标注员修正后重新提交
- 错误率 > 10%：批次退回返工 + 标注员需接受指导培训

**质检记录要求：** 每次质检必须记录以下信息：
- 抽检数量 / 合格数量
- 错误类型及数量（漏标、多标、标签错误、定位偏移等）
- 具体错误样本编号（方便标注员查找修正）
- 改进建议

### 第三级：专家仲裁

当质检员与标注员对某个标注结果存在意见分歧时，由领域专家最终裁定。

**仲裁触发条件：**
- 标注员与质检员对同一目标的标签选择不一致
- 标注规范中未明确涵盖的边缘案例（如"这算不算一辆车？"）
- 任务描述与实际情况存在冲突

**仲裁流程：**
1. 质检员标记争议样本，附带双方意见
2. 专家审核争议样本，做出最终裁定
3. 专家根据裁定结果更新标注规范（防止同类分歧再次发生）
4. 定期汇总仲裁案例，整理为培训案例集

## 质检流程的持续优化

### 质检数据分析

定期（每周/每月）分析质检数据，关注以下指标：
- **各类错误占比变化**：如果"标签混淆"错误突然增多，可能是标注员对新增标签不熟悉
- **各标注员错误率趋势**：如果某标注员错误率持续上升，可能是疲劳或态度问题
- **各标注类型的错误分布**：如"小目标"漏标率高，需考虑增加放大标注提示

### 反馈回路

质检的价值不仅在于"挑错"，更在于"改进"：

```
发现错误 → 记录分类 → 反馈标注员 → 标注员改进 → 质检验证 → 更新规范
```

关键原则：
- 反馈要及时（24 小时内）：延迟反馈会降低改进效果
- 反馈要具体（指出具体样本和错误类型）：不要说"你标得不好"，要说"第 3 张图的第 2 个框标签错了，应该是 bus 不是 truck"
- 反馈要建设性（附带改进建议）：不仅指出问题，还要说明正确做法

## 质检工具的技术支持

### 自动化质检

对于可自动化的质检项，应利用脚本辅助提高效率：
- 坐标越界检测：检查标注框是否超出图片范围（必须 100% 自动检测）
- 标签合法性检测：检查标签名称是否在定义的标签列表中
- 空标注检测：检查是否有任务提交时完全没有标注结果
- 异常尺寸检测：标注框面积过大（> 80% 图片面积）或过小（< 10 像素），标记为可疑

### 半自动化质检

- 随机抽查辅助：系统随机选取每批中的 N 张样本作为质检样本
- 差异标注对比：自动对比标注框与预标注模型的预测，高亮差异区域
