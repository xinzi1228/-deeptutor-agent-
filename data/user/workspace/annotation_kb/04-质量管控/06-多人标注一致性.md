# 多人标注一致性

在数据标注项目中，几乎不可能由单一个人完成所有标注任务。多人协作是常态，而多人标注一致性（Inter-Annotator Agreement, IAA）是衡量多人标注团队成熟度的核心指标。

## 为什么一致性重要

### 问题场景

假如图片中有 100 辆"家用轿车（sedan）"，标注员 A 认为其中 95 辆是 sedan，标注员 B 认为其中 85 辆是 sedan。两人对"什么是 sedan"的理解不同。

**后果：**
- 同一个模型训练目标（sedan），但训练数据中的"sedan 标记"包含了两种不同的视觉特征集合
- 模型困惑：到底哪组特征代表 sedan？
- 最终模型性能下降，无法准确识别 sedan

### 一致性的本质

一致性不是要求所有标注员的标注结果"完全相同"（这不现实），而是要求标注员的**判断标准**一致。
- 即使两个标注员画的框位置不完全重合，只要对"什么是目标"、"框应该多大"的判断标准一致，他们的结果在统计上就是可用的。

## 一致性的量化方法

### 方法一：Cohen's Kappa（两人一致性）

适用于比较两个标注员（或标注员与金标准）之间的分类标注一致性。

**公式：**

```
Kappa = (Po - Pe) / (1 - Pe)
```

其中：
- **Po**（观察一致率）= 两个标注员标注结果一致的样本数 / 总样本数
- **Pe**（随机一致率）= 两人随机标注也可能一致的概率

**为什么不能用简单的"一致率"：**

假设一个二分类任务（"是猫" vs "不是猫"），数据中 90% 是猫。
- 两人都标注"是猫"就有 81% 的概率随机一致
- 如果标注员偷懒，每张都标"是猫"，一致率高达 90%，但实际上完全没有标注价值

Kappa 系数通过减去 Pe 排除了随机一致的影响，反映了标注员的"真实一致"程度。

**Kappa 值解读标准：**

| Kappa 值 | 一致性程度 | 标注团队评价 |
|----------|-----------|------------|
| < 0.20 | 轻微一致 | 标注规范基本失效，需重建 |
| 0.21-0.40 | 一般一致 | 标注规范存在重大歧义 |
| 0.41-0.60 | 中等一致 | 规范有改进空间 |
| 0.61-0.80 | 高度一致 | **合格线，团队可正常运转** |
| 0.81-1.00 | 几乎完全一致 | 优秀，标注规范非常成熟 |

### 方法二：Fleiss' Kappa（多人一致性）

适用于比较三个或更多标注员之间的一致性。

**计算公式（简化理解）：**

Fleiss' Kappa 将 Cohen's Kappa 的概念扩展到多人场景：
- 计算每个样本上，标注员之间对各类别的标注比例
- 汇总所有样本的一致性，减去随机一致部分

**使用场景：** 当一个标注任务由 3 人以上完成时（如三人独立标注后进行投票合并），使用 Fleiss' Kappa 评估整体一致水平。

### 方法三：基于 IOU 的一致性（目标检测/分割任务）

对于框型标注（目标检测、实例分割），使用 IOU（交并比）评估空间一致性：

**计算步骤：**
1. 标注员 A 和 B 分别对同一图片进行标注
2. 计算两人的标注框中"匹配的框对"（IOU ≥ 0.5 视为匹配）
3. 基于匹配结果计算 Precision、Recall、F1

**一致性判标准：**

| IOU 匹配阈值 | 适用场景 |
|-------------|---------|
| IOU ≥ 0.5 | 标准目标检测（Pascal VOC 标准） |
| IOU ≥ 0.75 | 高精度目标检测（COCO 标准） |
| mIoU（Mean IOU） | 语义分割任务（所有类别的 IOU 均值） |

## 提升一致性的系统方法

### 阶段一：标注前（预防）

1. **编写详尽规范**
   - 每个标签附带 5+ 张示例图片（正面示例）
   - 每个标签附带 3+ 张边界案例（"容易标错"的图片）
   - 量化标准："框边距目标边缘 ≤ 5 像素"，而非"尽量贴合"

2. **统一培训**
   - 培训时长 ≥ 4 小时（不能只是"看一遍规范"）
   - 培训内容包括：规范讲解 → 示例演示 → 实操练习 → 小组讨论
   - 培训后考核：标注 10 张金标准样本，Kappa ≥ 0.7 方可上岗

3. **明确标注流程**
   - 制定标准操作顺序（如：先放大浏览 → 标注大目标 → 标注小目标 → 缩小复查 → 提交）
   - 确保每个标注员的标注操作流程一致

### 阶段二：标注中（监控）

1. **定期 Kappa 测试**
   - 每周一次：所有标注员独立标注 10 张相同的金标准样本
   - 计算每个人的 Kappa，不合格即时校准

2. **质检交叉验证**
   - 让质检员在抽检时记录"需要修正"的标注框及原因
   - 每周汇总"高频修正项"，更新标注规范或补充培训

3. **锚定样本定期回检**
   - 标注员每天开始工作时先标注 3 张锚定样本
   - 系统自动对比锚定样本的标准答案，提醒偏差

### 阶段三：标注后（校准）

1. **争议仲裁机制**
   - 对质检中标注员与质检员意见不一致的样本，由专家裁定
   - 仲裁结果记录在案，更新规范

2. **反馈会议（每周）**
   - 公布本周 Kappa 测试结果
   - 匿名展示本周"最容易产生分歧的 5 个样本"及其标准答案
   - 让标注员讨论"为什么当时会这样判断"，促进理解一致

3. **规范持续更新**
   - 将本周的所有仲裁和反馈案例加入规范文档
   - 更新锚定样本库

## 一致性管理的常见陷阱

| 陷阱 | 说明 | 规避方法 |
|------|------|---------|
| "高质量标注员不需要一致性管理" | 即使水平高的标注员之间也可能存在理解偏差 | 所有标注员一视同仁，统一参与校准测试 |
| "一致性达标就不用管了" | 一致性是动态的，可能随时间漂移 | 保持定期测试，不可"一劳永逸" |
| "只管 Kappa，不看原始数据" | Kappa 是汇总指标，不能反映具体分歧类型 | 结合原始错误分类数据进行分析 |
| "计算 Kappa 太麻烦" | 手动计算确实繁琐 | 使用 Python 脚本或工具自动计算 |
