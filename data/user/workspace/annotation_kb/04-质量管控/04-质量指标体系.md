# 质量指标体系

建立科学的质量指标体系是量化评估标注质量和标注员绩效的基础。指标体系分为核心质量指标和过程效率指标两大类。

## 核心质量指标

### 准确率（Accuracy）

**公式：** `Accuracy = (TP + TN) / (TP + TN + FP + FN)`

- TP（True Positive）：正确标注的目标数
- TN（True Negative）：正确判断为背景的区域
- FP（False Positive）：错误标注的目标数（多标）
- FN（False Negative）：遗漏标注的目标数（漏标）

**含义：** 所有判断（包括标注和未标注区域）中正确的比例。适用的场景是分类任务和检测任务中背景区域占比大的情况。

**局限性：** 当正负样本极不均衡时（如图片中目标很少，大部分是背景），准确率会虚高。因此不能单独使用准确率来评估检测标注质量。

**合格标准：** ≥ 95%
**优秀标准：** ≥ 98%

### 精确率（Precision）

**公式：** `Precision = TP / (TP + FP)`

**含义：** 所有被标注为"目标"的结果中，真正是目标的比例。衡量标注员"不乱标"的能力。

**解读：**
- 精确率高意味着标注员画的框绝大多数都是正确的
- 精确率低意味着标注员画了很多不应该画的框（多标问题严重）

**合格标准：** ≥ 95%
**优秀标准：** ≥ 98%

### 召回率（Recall）

**公式：** `Recall = TP / (TP + FN)`

**含义：** 所有真实存在的目标中，被标注员找到并标注的比例。衡量标注员"不遗漏"的能力。

**解读：**
- 召回率高意味着标注员找到了几乎所有应该标注的目标
- 召回率低意味着标注员漏标了很多目标

**合格标准：** ≥ 93%
**优秀标准：** ≥ 97%

**注意：** 召回率通常比精确率更难达到高水平，因为"找到所有目标"比"不乱标"更具挑战性。对于小目标和遮挡目标较多的场景，可适当降低召回率的合格线。

### F1 分数

**公式：** `F1 = 2 × Precision × Recall / (Precision + Recall)`

**含义：** 精确率和召回率的调和平均值，综合考虑"不乱标"和"不遗漏"两项能力。

**解读：**
- F1 是一个平衡指标，只有当精确率和召回率都高时，F1 才会高
- 如果标注员为了追求高召回率而大量多标（降低了精确率），F1 会显著下降
- 如果标注员为了追求高精确率而画得过于保守（降低了召回率），F1 同样会下降

**合格标准：** ≥ 0.94
**优秀标准：** ≥ 0.97

### IOU（交并比）

**公式：** `IOU = 标注框与真值框的交集面积 / 标注框与真值框的并集面积`

**含义：** 衡量标注框与标准答案的重合程度。IOU = 1.0 表示完全重合，IOU = 0 表示完全不重合。

**解读：**
- IOU ≥ 0.5 通常视为"匹配成功"（框的位置基本正确）
- IOU ≥ 0.75 视为"良好"
- IOU ≥ 0.9 视为"优秀"

**适用范围：** 目标检测、实例分割的标注质量评估。

### Kappa 系数

**公式：** `Kappa = (Po - Pe) / (1 - Pe)`

其中 Po 为实际一致率，Pe 为随机一致率。

**含义：** 衡量两个标注员（或标注员与标准答案）之间的一致性，剔除了随机一致的影响。

**Kappa 值解读：**
| Kappa 范围 | 一致性程度 | 行动建议 |
|-----------|-----------|---------|
| < 0.41 | 差 | 重新培训标注规范 |
| 0.41-0.60 | 一般 | 细化边界案例说明 |
| 0.61-0.80 | 良好 | 可接受，持续监控 |
| > 0.81 | 优秀 | 高度一致，规范成熟 |

**合格标准：** ≥ 0.70
**优秀标准：** ≥ 0.85

## 过程效率指标

| 指标 | 定义 | 参考基准 | 说明 |
|------|------|---------|------|
| 日人均标注量 | 每天每人的平均标注任务数 | 图像检测：200-500 张/天 | 受任务复杂度影响，复杂任务（多框/多边形）远低于此值 |
| 质检退回率 | 被质检退回返工的批次占比 | < 5% | 退回率过高说明标注员质量控制不足 |
| 一次通过率 | 一次质检即通过的批次占比 | > 90% | 平均修正次数 < 1.5 次/张 |
| 标签切换频率 | 每分钟切换标签的次数 | < 3 次/分钟 | 频繁切换标签降低效率，建议按标签分批标注 |
| 标注员留存率 | 6 个月内仍在岗的标注员比例 | > 80% | 流失率过高会导致培训成本激增和质量波动 |

## 指标的综合应用

### 标注员能力雷达图

使用雷达图同时展示标注员的多个质量指标，直观定位优势和短板：

```
        精确率
          /\
         /  \
  标签正确率  召回率
        |      |
  定位精度 — IOU均值
```

雷达图示例：某标注员精确率 98% + 召回率 88%（优劣势明显）→ 建议加强"防遗漏"训练。

### 动态阈值管理

不要固守一个固定标准，应根据项目阶段和数据类型动态调整：

- **项目初期**（标注员培训阶段）：降低标准，容忍较高错误率，以保护标注员信心
- **项目中期**（标注员熟练后）：执行严格标准，不合格退回返工
- **安全关键数据**：所有指标执行优秀线标准（精确率 ≥ 98%、召回率 ≥ 97%）
- **非关键数据**：可适当放宽至合格线标准

### 质量趋势监控

绘制指标的时间序列折线图，监控质量变化趋势：
- **上升趋势**：培训效果显现，团队成熟度提升
- **平稳趋势**：团队稳定性好，管理体系成熟
- **下降趋势**：可能原因：疲劳积累、规范漂移、新任务适应期

下降趋势的应对：及时介入→排查原因→针对性改进（而非等到跌出合格线才应对）。
