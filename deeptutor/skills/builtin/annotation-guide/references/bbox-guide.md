# 目标检测标注 (Bounding Box Annotation)

> 对应任务: task1,2,3,4,6,7,8
> 对应知识点: 边界框绘制规范、遮挡目标处理、小目标标注策略
> 适用阶段: Phase1 理论 Step1 / Phase2 实践 Step5 逐框反馈

## 边界框基本规则

1. **最小外接矩形** — 框边与目标边缘间距 ≤ 5 像素
2. **完整性** — 不能只框目标的一部分，必须包含整体
3. **不重复** — 同一目标只标一个框

## 遮挡目标处理

| 遮挡程度 | 处理规则 |
|---------|---------|
| 遮挡 > 70% | 不标注 |
| 遮挡 30%-70% | 标注可见部分，按上下文推断完整边界 |
| 遮挡 < 30% | 正常标注 |

标注规范: 以"目标中心点是否可见"为判定标准。中心点可见 → 标注。不可见 → 不标注。
(参考 COCO Dataset Annotation Guidelines §3.4)

## 小目标标注

- 面积 < 32×32 像素 → 多目标检测中的"小目标"
- 标注技巧: 放大 200% 后画框 → 检查后再缩小 → 确保四边都不漏
- 扫描策略: 由大到小，从左到右，从上到下 Z 字形扫描

## 多边形分割

- 沿目标边缘精确描画闭合多边形
- 控制点间距 ≤ 5 像素
- 顺时针方向
- 支持格式: COCO JSON (segmentation)、LabelMe JSON
- 关键指标: Pixel IOU、mIoU

## 关键点标注

- 人体关节点: 17 点模型（COCO）或 21 点模型
- 遮挡关键点: 根据解剖结构合理推断
- 关键指标: OKS (Object Keypoint Similarity)

## 常见错误及预防

| 错误类型 | 原因 | 预防规则 |
|---------|------|---------|
| 框太大（留白多） | 最小外接概念不清晰 | "画完后检查四边间距是否都 ≤ 5px" |
| 框太小（截断目标） | 只标了目标的一部分 | "画完后确认目标四边都在框内" |
| 框偏移 | 鼠标抖动或缩放不够 | "放大到 150% 以下画框，用方向键微调" |
| 漏标小目标 | 没注意到角落/边缘的小物体 | "从左上到右下 Z 字扫描，检查四角" |
| 遮挡目标漏标 | 不确定遮挡判断标准 | "中心点可见 → 标；不可见 → 不标" |
