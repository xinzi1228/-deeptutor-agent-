# 分类标注 (Classification)

> 对应任务: task5, task9
> 对应知识点: 图像分类基础、单标签分类、多标签分类
> 适用阶段: Phase1 理论 Step1 / Phase2 实践 Step5

## 单标签分类

每张图只属于一个类别。如: 猫 vs 狗、有车 vs 无车。

评测指标: Accuracy = 正确数 / 总数

## 多标签分类

每张图可属于多个类别。如: 场景中同时出现"人""车""自行车"。

评测指标: F1 Score (逐标签算 Precision/Recall)

## 常见错误

| 错误 | 原因 | 预防 |
|------|------|------|
| 只看局部不完整 | 没看整张图就下判断 | "标注前浏览完整图片" |
| 主观判断不一致 | 标准模糊（如"这张图美不美"） | 避免主观分类，改为可量化指标 |
| 忽略上下文 | 餐厅外景被分到"室内场景" | "确认场景全部可见再分类" |
| 细粒度分类不准确 | 区分哈士奇和阿拉斯加 | 提供对比特征表（耳朵/尾巴/体型） |
