# 最佳实践与常见陷阱

> 适用阶段: Phase1 理论 Step1

## 标注指南设计 4 原则

1. **具体再具体** — "只标注前挡风玻璃里可见的车辆"，不是"标车"
2. **包含边界案例** — 什么算"遮挡"？目标部分可见时什么时候该标？
3. **使用可视化示例** — 正确 ✅ 和错误 ❌ 的标注都要给
4. **定义标签优先级** — 多个标签都可能适用时，用哪个？

## 标注工作流 4 步

1. **试点批次** — 标 100 个样本，评审分歧，修订指南
2. **一致性检查** — 每批后计算标注者间 Kappa
3. **边界案例日志** — 记录模糊案例和裁决
4. **定期重校准** — 定期重新标注"金标准"样本集

## 6 种常见陷阱

| 陷阱 | 表现 | 解决 |
|------|------|------|
| **标签不一致** | 同一类物体不同人标得不一样 | 定期校准会 + 清晰的带示例指南 |
| **边界模糊** | 框的边缘该在哪里意见不同 | 写死规则（如"框包含尾巴"） |
| **标注疲劳** | 后半段的框明显比前半段粗糙 | 每 45-60 分钟强制休息 |
| **类别不平衡** | 某一类样本远多于其他类 | 评审时过采样稀类，分层抽样 |
| **确证偏见** | 标注员只按自己的习惯标 | 轮换标注员到不同数据源 |
| **标准漂移** | 标注员的标准随时间悄悄变化 | 试点后锁定指南，版本控制 |

## 标注员自检清单

- [ ] 所有需要标注的目标类型都已标注？
- [ ] 每个框的标签类别正确？
- [ ] 每个框满足最小外接矩形（边距 ≤ 5px）？
- [ ] 没有明显漏标（逐一扫描图片每个区域）？
- [ ] 没有明显多标（非目标物体不应被框选）？
- [ ] 被遮挡/截断的目标标记了相应属性？
