# 文本标注规范指南

> 用于数据标注教学平台「标注星图」。本文档是文本标注教学的基本规范，供 Coach 教学时引用。

## 一、文本标注基本概念

文本标注是对原始文本数据进行结构化标记的过程，使机器能够理解文本中的语义信息。

### 主要标注类型

| 类型 | 说明 | 典型应用 |
|------|------|----------|
| **命名实体识别(NER)** | 识别文本中的人名、地名、机构名、术语等 | 信息抽取、知识图谱 |
| **文本分类** | 对整段文本进行类别判定 | 情感分析、意图识别、质量评级 |
| **关系抽取** | 识别实体之间的语义关系 | 知识图谱构建 |
| **序列标注** | 对文本中的每个token进行标注 | 分词、词性标注 |

## 二、NER 标注规范

### 2.1 实体定位原则
- 使用 **start（起始字符位置，0-based）** 和 **end（结束字符位置，不包含）** 表示实体位置
- 实体必须是连续的文本片段，不允许跨句标注
- 实体边界应精确到字符级别

### 2.2 实体类型体系
- **term**：标注领域术语（如"边界框"、"IOU"、"语义分割"）
- **standard**：标准规范类实体（如"GB/T 41867"、"COCO格式"）
- **format**：数据格式类实体（如"VOC XML"、"JSON数组"）

### 2.3 标注规则
1. **完整性**：实体必须包含完整的短语，不能截断
2. **唯一性**：同一位置的文本只能属于一个实体类型
3. **最小原则**：选择最小的能表达完整语义的文本片段

## 三、文本分类标注规范

### 3.1 分类原则
- 每条文本必须有且仅有一个分类标签
- 分类标签必须互斥，覆盖所有可能情况
- 标注前必须明确每个标签的定义和边界条件

### 3.2 标注质量等级
- **高质量(quality_good)**：描述完整、格式规范、标签正确
- **部分合格(quality_partial)**：基本正确但有小瑕疵
- **不合格(quality_bad)**：格式错误、标签错误或信息缺失

## 四、评价指标

### 4.1 NER 评估
- **实体级 F1**：精确匹配 start/end/label 三元组
- 精确率 = 正确实体数 / 用户标出实体数
- 召回率 = 正确实体数 / 标准答案实体数

### 4.2 文本分类评估
- **准确率(Accuracy)**：正确分类数 / 总题目数

### 4.3 一致性检验
- 多人标注场景下使用 **Cohen's Kappa** 系数
- Kappa ≥ 0.6 合格，≥ 0.8 优秀

## 五、常见错误与改进建议

1. **实体截断**：实体不完整，如将"边界框绘制"标为"边界框"——缺少"绘制"
2. **实体过度**：包含不必要的修饰词，如"精确的边界框"——应只标"边界框"
3. **类型混淆**：将"COCO"标为term而非format
4. **边界错误**：start/end算错1个字符
