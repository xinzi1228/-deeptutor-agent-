# 视频/音频标注规范指南

> 用于数据标注教学平台「标注星图」。本文档是视频和音频标注教学的基本规范。

## 一、视频标注基本概念

视频标注是对连续帧序列进行结构化标记，与图像标注的核心区别在于**增加了时间维度**。

### 主要标注类型

| 类型 | 说明 | 典型应用 |
|------|------|----------|
| **帧级目标检测** | 在指定帧上画矩形框标注目标 | 自动驾驶、安防监控 |
| **目标跟踪** | 跨帧持续跟踪目标位置变化 | 行为分析、运动轨迹 |
| **事件检测** | 标记特定事件的起止时间段 | 异常行为、动作识别 |

## 二、帧级标注规范

### 2.1 标注原则
1. **逐帧对齐**：每帧的bbox必须贴合该帧目标轮廓，不能套用上一帧
2. **完整性**：帧内所有可见目标都应标注，包括部分遮挡的目标
3. **连续性**：同一目标在相邻帧的bbox应平滑过渡，不能跳跃

### 2.2 目标进出画面
- 目标部分进入画面时：标注可见部分
- 目标完全离开画面后：停止标注
- 目标被遮挡 > 50% 时：可暂停标注

### 2.3 标注格式
```json
{
  "frame": 5,
  "boxes": [
    {"x": 100, "y": 200, "w": 150, "h": 120, "label": "car"}
  ]
}
```

## 三、视频事件检测规范

### 3.1 事件定义
- 事件必须有明确的起始时间和结束时间
- 事件类型互斥或可重叠（根据任务要求）

### 3.2 时间精度
- 起止时间精确到 0.1 秒
- 事件边界应在动作/状态变化的瞬间

### 3.3 评估指标
- **tIoU（时序IOU）**：intersection / union of 时间段
- **segment F1**：基于tIoU阈值(≥0.3)的精确率/召回率

## 四、音频标注规范

### 4.1 音频事件检测
- 标出每种声音的start_time和end_time
- 常见类型：speech(语音)、music(音乐)、noise(噪音)
- 允许多个事件重叠（如背景音乐+人声）

### 4.2 语音转写（ASR标注）
- **WER（词错率）** = (替换+删除+插入)/参考词数
- 转写规范：保留说话人原意，补全省略语，统一标点
- WER < 10% = 优秀，< 30% = 可接受

## 五、评价指标对照

| 模态 | 任务类型 | 核心指标 |
|------|---------|----------|
| 视频 | 帧级bbox | 逐帧IOU、平均F1 |
| 视频 | 目标跟踪 | MOTA、MOTP、帧正确率 |
| 视频 | 事件检测 | tIoU、segment F1 |
| 音频 | 事件检测 | tIoU、segment F1 |
| 音频 | 语音转写 | WER、字符准确率 |

## 六、常见错误

1. **帧间不一致**：同一目标在相邻帧的框大小突变
2. **漏检帧**：目标持续存在，但中间某帧未标
3. **时间边界模糊**：事件起止时间与实际不符
4. **转写遗漏**：语音转写中省略关键词语
