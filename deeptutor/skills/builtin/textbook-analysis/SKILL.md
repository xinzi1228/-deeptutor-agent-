# 教材内容分析

只分析系统教材导入任务产生的 `textbook_markdown` 产物。不要读取任意路径、原始账号数据或其他学习档案。

## 工作流

1. 调用 `textbook_candidate(action="read", job_id=...)` 读取可追溯 Markdown 和受控来源。
2. 按章节提取术语、知识点、步骤、安全规范、摘要和候选题；每项保留 `source_pages`。
3. 遇到教材与国家/行业标准表述不一致时生成 `conflict`，不要自行裁决。
4. 按 [输出契约](references/output-contract.md) 组织候选数据。
5. 调用 `textbook_candidate(action="submit", ...)` 写入内容治理待审核区。

## 强制边界

- 不补写教材没有的信息，不把经验阈值冒充强制标准。
- 不发布、不删除原文件、不改正式知识库或题库。
- 没有具体源页的条目不得提交。
- 安全规范若标记为强制要求，必须同时引用受控国家或行业标准。
- 只向总控返回候选编号、冲突编号和待人工确认事项。
